第3章　臺灣的地形

一、章節主題與學習目標

一句話主題： 臺灣的地形是由板塊運動與流水等自然力量共同塑造，而不同地形的高度、坡度和分布，也決定了人類如何利用土地。

學完本章，學生應能：

  1. 說明內營力與外營力如何形成臺灣的地形。
  2. 辨識山地、丘陵、台地、盆地、平原五大地形。
  3. 判讀等高線、分層設色圖及地形剖面圖。
  4. 說出臺灣五大山脈、主要平原、盆地、台地的分布。
  5. 分析地形如何影響農業、聚落、交通與環境安全。

核心觀念：地形不只決定我們看見什麼景觀，也影響我們能在哪裡生活、耕作與建設。

二、地形是如何形成的？

3-1 地形的形成力量

【三版共通】

地形是地表高低起伏的形貌。地表並不是永遠不變，而是受到地球內部與外部兩種力量影響。

比較項目 內營力 外營力
力量來源 地球內部 地球外部的自然作用
主要作用 板塊運動、地殼抬升、火山活動 風化、侵蝕、搬運、堆積
對地形的影響 形成山脈、火山及地表高低差 切割山地、形成河谷與堆積平原
臺灣例子 中央山脈的隆起、陽明山火山地形 太魯閣峽谷、嘉南平原、河流沖積扇
記憶重點 改變地殼構造與高度 改造地表形貌

【脈絡補充】內營力與外營力並不是互相排斥的力量，而是會持續共同作用。

臺灣地形形成的因果鏈 / 板塊擠壓 / 地層褶曲、斷裂與抬升 / 形成高聳的山地 / 雨水與河流侵蝕、搬運土砂 / 形成河谷、沖積扇與平原 / 這是方便理解的簡化流程。實際上，地殼抬升與侵蝕、堆積可以同時進行。

3-2 為什麼臺灣山多、平原少？

【三版共通】

臺灣位於歐亞板塊與菲律賓海板塊的交界帶。兩個板塊長期互相擠壓，使岩層褶曲、斷裂、抬升，逐漸形成臺灣的山脈。

因此臺灣具有以下地形特色：

  • 山地面積廣大，平原相對較少。
  • 主要山脈大致呈南北走向。
  • 地勢高聳，坡度陡峭。
  • 地質構造複雜，地震活動頻繁。
  • 山區河流坡降大，流水侵蝕作用明顯。

wordwall.net

讀圖方向：臺灣中央偏東為廣大的山地，西部則有較寬廣的平原、丘陵與台地。

【版本差異】

  • （南一） 課本記載山地約占臺灣總面積47%。
  • （翰林） 課本記載山地與丘陵合計約占總面積70%。
  • （康軒） 強調板塊推擠形成新褶曲山脈，並著重地形年輕、地勢陡峭、地質破碎等特色。

易混淆提醒： 47%與70%不是互相矛盾。前者統計「山地」，後者把「山地與丘陵」合併計算。統計的地形範圍不同，結果自然不同。

3-3 真實案例：花蓮玉富自行車道

【南一／翰林】

花蓮玉里一帶位於板塊交界帶，舊鐵道橋梁曾因地殼擠壓與抬升而逐漸變形，後來部分舊鐵道改建成玉富自行車道，成為認識板塊運動的戶外地理教室。

  • 地理位置： 花東縱谷。
  • 主要作用力： 內營力中的板塊運動。
  • 地理意義： 讓學生了解板塊活動不只發生在遠古時代，現在仍持續進行。
  • 補充提醒： 自行車道舊鐵橋與玉里公路橋是不同設施，不應將兩者的變形紀錄混為一談。

查證來源：交通部觀光署花東縱谷國家風景區管理處：玉富自行車道。官方資料也記載玉富舊鐵橋曾因2022年地震暫停開放進行維修，因此教學時不宜直接宣稱目前全線可通行。交通部觀光署花東縱谷國家風景區管理處-自行車主題網

三、臺灣有哪些地形類型？

3-4 六種基本地形與臺灣五大地形

【三版共通】

一般地理分類可以認識山地、高原、丘陵、台地、盆地及平原六種地形。

不過，臺灣沒有廣大而典型的高原地形，所以課本主要介紹五大地形：山地、丘陵、台地、盆地、平原。

地形 主要特徵 臺灣代表地區 主要土地利用
山地 通常海拔1,000公尺以上，坡度陡、起伏大 中央山脈、雪山山脈、玉山山脈 森林保育、水源涵養、登山觀光
丘陵 通常低於1,000公尺，連綿起伏，坡度較緩 苗栗丘陵、新竹丘陵 茶園、果園、部分聚落
台地 頂部平坦，地勢較周圍高，邊緣常有陡坡 桃園台地、林口台地、大肚台地 農業、工業、住宅與公共設施
盆地 四周較高，中間相對低平 臺北盆地、臺中盆地、埔里盆地 都市、商業、交通與農業
平原 地勢低平、範圍較開闊，起伏小 嘉南平原、屏東平原、蘭陽平原 農業、聚落、交通及工業

表格彙整三版共同的地形特徵；地名取自三版出現的實例。

圖像記憶：五大地形的外觀

山地：高而陡峭 / 丘陵：低緩起伏 / 台地：頂平、邊緣較陡 / 盆地：四周高、中間低 / 平原：低平、開闊

【脈絡補充】

五大地形不能只靠「海拔高低」判斷，還必須觀察地表起伏、坡度及周圍地勢。

例如：台地與平原都可能有平坦地表，但台地通常比周圍低地高；盆地即使海拔不高，關鍵特徵仍是四周環繞較高的地形。

3-5 五大山脈與重要地形的分布

【三版共通】

臺灣五大山脈為：

山脈 位置與特色
中央山脈 臺灣中央偏東，縱貫南北，素有「臺灣屋脊」或「臺灣脊梁」之稱
雪山山脈 主要位於北部至中部山區
玉山山脈 主要位於中南部，玉山主峰是臺灣最高峰
阿里山山脈 主要位於中央山脈西側的中南部
海岸山脈 位於花東縱谷東側，接近臺灣東岸

玉山主峰海拔3,952公尺，是臺灣最高峰；但中央山脈是臺灣重要的南北向地形骨幹，最高峰不在中央山脈。

查證來源：玉山國家公園管理處：地形。ysnp.gov.tw

【三版共通】重要地形分布也要認識：

  • 平原： 以西部較廣，嘉南平原面積最大；東部也有蘭陽平原、花東縱谷平原等。
  • 丘陵： 多分布於山地外緣，例如新竹、苗栗丘陵。
  • 台地： 例如林口、桃園、大肚、八卦台地。
  • 盆地： 例如臺北、臺中、埔里盆地。

【脈絡補充】花東縱谷雖名為「縱谷」，但谷底有平坦地形，沿線農業及聚落分布與兩側山地明顯不同，因此南一版將它列入重要的平原地區。

3-7 等高線判讀：段考重要技能

【三版共通】

等高線是把海拔高度相同的各點連接而成的曲線。

掌握以下規則：

  1. 同一條等高線上的各點海拔高度相同。
  2. 同一張一般等高線地形圖，相鄰等高線通常有固定的高度差，稱為等高距。
  3. 等高線密集，表示坡度較陡。
  4. 等高線稀疏，表示坡度較緩。
  5. 等高線在河谷或山脊附近彎曲時，可配合高度判斷地形。

示意圖：等高線密度與坡度 / 兩側示意圖的等高距相同，差別在等高線的水平間距。

海拔高度與相對高度

  • 海拔高度： 某地相對於平均海平面的高度。
  • 相對高度： 兩個地點之間的高度差。

例：甲地海拔800公尺，乙地海拔300公尺，兩地相對高度為：

800 / − / 300 / = / 500 /  公尺 / 800−300=500 公尺

3-8 河谷與山脊的判讀

【三版共通】

判讀項目 河谷 山脊
地形外觀 兩側較高、中間較低 中間較高、兩側較低
等高線彎曲方向 V字尖端指向高處 V字尖端指向低處
地表水流 常匯集成溪流 水向兩側分流
常見題目 找河道、流水方向 找登山稜線、分水嶺

記憶口訣：河谷V尖朝高處，山脊V尖朝低處。

【脈絡補充】這個口訣適用於典型的山脊、河谷等高線形狀。實際地圖仍應先看等高線標高，不能只看V字形就猜答案。

3-9 如何畫地形剖面圖？

【三版共通】

  1. 在等高線地形圖上畫出一條剖面線，例如A—B。
  2. 找出剖面線與各條等高線的交點。
  3. 將交點按照水平位置與海拔高度，標在下方座標圖。
  4. 依照地表起伏把各點連成平滑曲線。

段考提醒： 地形剖面圖表示的是「沿線高度變化」，不是把等高線原圖直接複製到下方。

五、不同地形如何影響人類生活？

3-10 地形、土地利用與環境問題的關係

【三版共通】

人類通常比較容易在平坦、交通便利、水源較容易取得的地區生活。

但隨著人口增加、產業發展，開發逐漸延伸到坡地與山區，也可能帶來新的環境問題。

地形 發展上的優勢 主要限制或環境風險
平原 地勢平坦、農業與交通便利 洪水、低窪積水、都市擴張
盆地 底部平坦、適合聚落 通風較差、局部空氣污染累積、淹水風險
台地 頂部平坦、可供建設 部分地區取水或灌溉不易，邊坡需注意安全
丘陵 適合茶園、果園與部分住宅 坡地開墾不當可能水土流失
山地 森林、水源、生態及觀光資源豐富 山崩、落石、土石流、道路維護困難

【脈絡補充】「適合人類使用」並不代表「可以無限制開發」。即使是平原，若占用河川行水區或破壞濕地，也可能提高災害風險。

3-11 真實案例：桃園台地的埤塘

【南一／翰林】

桃園台地地勢較高，部分地區缺乏穩定而充足的天然灌溉水源。

過去居民便開挖許多埤塘，把雨水及地表逕流儲存起來，用來灌溉農田。

iatyu.nat.gov.tw

台地地形與河川特性 → 灌溉水源不足 → 開挖埤塘蓄水 → 發展農業與埤塘文化。

【脈絡補充】如今埤塘除了灌溉，還有蓄水、滯洪、生態棲地等功能。

3-12 真實案例：山坡地開發與土石流

【康軒】

康軒版以南投縣仁愛鄉南豐村屢次遭土石流侵襲的加油站，讓學生思考地形、豪雨、地震及土地利用的關係。

【南一／翰林】

南一以清境地區觀光開發為例，翰林則以高山高麗菜種植探討坡地開墾與水土保持；兩個案例均安排在第4章延伸閱讀中。

【三版共通的學習核心】

土石流常涉及下列條件：

  • 山區或溪谷具有一定坡度。
  • 坡面或溪床存在可被帶動的土砂。
  • 強降雨等因素讓大量土砂和水混合並向下移動。

坡地開發與災害風險的關聯 / 簡化示意：強降雨可能使山區土砂沿坡面或溪谷向下移動。並非所有豪雨或坡地開發都必然造成土石流。

可能的風險增加過程：

坡地過度開墾 → 植被減少、土壤裸露 → 雨水沖蝕加強 → 土砂供應增加 → 在不利地形與強降雨條件下，可能提高土石流風險。

重要觀念： 土石流不是只有人類開發才會發生的災害。地震、地質破碎與豪雨等自然因素也可能引發；人類活動則可能改變風險程度。

查證來源：農業部農村發展及水土保持署：土石流介紹、坡地安全與土石流警戒機制（2026年）。246.ardswc.gov.tw+1

3-13 如何讓土地永續利用？

【康軒】特別強調山坡地開發限制、保護區設立及永續利用的觀念。

【南一／翰林】藉由清境開發、梯田與高山農業等案例，討論產業發展和環境保育的平衡。

【脈絡補充】

可以採取以下方式：

  • 在不適合開發的陡坡與高風險區，限制新的開發。
  • 保護森林植被與河川上游集水區。
  • 農地依坡度與地質條件，採取適當的水土保持措施。
  • 配合土石流警戒資訊，規劃疏散避難。
  • 在觀光與農業發展時，兼顧當地居民生活與自然環境。

永續利用不是完全禁止開發，而是在滿足現在需求的同時，不破壞未來世代使用環境的機會。

第3章常見段考題型

題型1：地形特徵判斷

題目：臺灣山脈多呈南北走向，地勢高聳陡峭，最主要受到何者影響？

答案：板塊運動產生的內營力。

題型2：等高距計算

題目：800公尺和1,000公尺兩條等高線之間，另有3條等高線，等高距是多少？

計算：將200公尺的高度差分成4個間隔。

答案：50公尺。

題型3：山脊與河谷

題目：等高線彎曲形成V字形，尖端指向海拔較高處，最可能是哪種地形？

答案：河谷。

題型4：地形與土地利用

題目：臺灣西部平原為何比中央山區更適合發展大規模農業與都市？

答案：平原地勢低平，較方便耕作、興建道路與聚落。

題型5：地形災害因果分析

題目：在坡地大量砍樹、整地，可能造成什麼環境影響？

答案：可能增加地表沖蝕、水土流失與邊坡不穩定風險，在豪雨等條件下提高災害發生的可能性。

第4章　臺灣的海岸與島嶼

康軒版稱〈臺灣的海域〉；南一版稱〈臺灣的海岸與島嶼〉；翰林版稱〈海岸與島嶼〉。

一、章節主題與學習目標

一句話主題： 臺灣的海岸因地形、地質、海浪及生物作用而呈現不同樣貌，並影響港口、漁業、養殖、觀光及海洋資源的利用。

學完本章，學生應能：

  1. 說明沙岸、岩岸及珊瑚礁海岸的形成原因與特色。
  2. 辨識臺灣北部、西部、南部與東部的主要海岸類型。
  3. 分析海岸特徵如何影響港口、漁業、養殖與觀光。
  4. 比較大陸島、火山島與珊瑚礁島的形成原因。
  5. 認識領海與專屬經濟海域的基本概念。
  6. 理解海岸開發、海洋資源利用與環境保育之間的關係。

核心觀念：同樣面對海洋，不同海岸的地形條件不同，人類能從事的活動也不相同。

二、海岸是如何形成的？

4-1 海岸的基本分類

【三版共通】

海岸是海洋與陸地交界的地帶。

海岸可依照組成物質及地形特徵分類。國中階段首先認識沙岸與岩岸，再進一步認識珊瑚礁海岸等特殊類型。

【翰林】在基本海岸分類中，另將珊瑚礁海岸獨立介紹。

比較項目 沙岸 岩岸
主要成因 河流、海浪及海流搬運並堆積泥沙 山地或丘陵逼近海洋，岩石受到侵蝕
主要物質 沙、泥、礫石等沉積物 岩石
海岸線 通常較平直 通常較曲折
陸地地勢 沿岸較平坦 沿岸較陡峭
海水深度 通常較淺 通常較深
常見地形 沙灘、沙洲、潟湖 岬角、灣澳、海蝕崖
常見利用 養殖、鹽業、海水浴場 港口、航運、捕撈漁業、觀光

【脈絡補充】這些是臺灣國中課本中的典型比較特徵，不表示所有沙岸都一定平直，也不表示每一處岩岸都適合建港。實際利用仍要考慮水深、風浪、航道及交通條件。

4-2 沙岸的形成過程

【三版共通】

河流將山區土砂搬運到下游與河口，部分土砂在沿岸受到海浪與海流作用，逐漸堆積形成沙岸。

沙岸形成的因果關係 / 山區岩石風化、侵蝕 / 河川搬運泥沙 / 泥沙進入河口與沿岸 / 海浪、海流搬運與重新堆積 / 形成沙灘、沙洲、潟湖等地形

沙洲與潟湖

【三版共通】

沙洲是泥沙在淺海或河口附近堆積而成、露出水面的狹長或堤狀地形。

潟湖是海岸與沙洲等地形圍成、與外海部分相通的半封閉水域。

潟湖位於陸地與沙洲之間，通常與外海仍有水道相連，並不是完全封閉的淡水湖。

【脈絡補充】

沙洲可減弱部分外海波浪，使後方潟湖比較平靜，適合部分養殖活動。然而沙洲也會隨海流、風浪與土砂供應改變位置、形狀和大小。

4-3 岩岸與岬灣海岸的形成

【三版共通】

山地或丘陵接近海洋時，沿岸可能形成由岩石構成的陡峭海岸。

當岩層的抗侵蝕能力不同，海浪長期作用後，可能形成岬角與灣澳相間的地形。

  • 岬角： 向海洋突出的陸地。
  • 灣澳： 海岸向陸地凹入的水域。

【康軒】特別解釋軟硬岩交互排列、山脈走向與海岸線的關係，是形成典型岬灣海岸的重要條件之一。

岩層條件 受海浪長期侵蝕後
抗侵蝕能力較強的岩層 相對凸出，可能形成岬角
抗侵蝕能力較弱的岩層 相對凹入，可能形成灣澳

常見段考觀念：硬岩相對凸出，軟岩相對凹入。

【脈絡補充】除了岩石軟硬，岩層排列、節理、斷層及波浪方向，也會影響海岸的實際形狀。

4-4 珊瑚礁海岸如何形成？

【三版均介紹南部珊瑚礁海岸】

珊瑚蟲是動物，不是植物。許多造礁珊瑚會分泌碳酸鈣骨骼，經過長時間累積，形成珊瑚礁。

珊瑚礁較適合在溫暖、陽光充足、水質清澈、適當深度的海水中生長。

【南一】進一步說明珊瑚礁受到地殼抬升，露出水面後，可能形成隆起珊瑚礁海岸。

【脈絡補充】活珊瑚礁與已抬升到陸地上的珊瑚礁石灰岩，是不同的狀態。

  • 海水中的活珊瑚礁：有活珊瑚及其他礁區生物。
  • 抬升的珊瑚礁石灰岩：過去的珊瑚礁已露出海面，成為陸地岩石。

三、臺灣四大海岸的分布與利用

4-5 四段海岸比較表

【三版共通】

國中階段常將臺灣本島海岸歸納為四個主要地理類型。

區域 主要海岸類型 地形特色 主要利用 代表地點
北部 岬灣海岸 岬角、海灣相間，海岸曲折 港口、航運、捕撈、觀光 基隆港、鼻頭角、野柳
西部 沙岸 海灘較寬、海水較淺，多沙洲、潟湖 魚塭、養蚵、鹽業、觀光 七股潟湖、北門、布袋
南部 珊瑚礁海岸 珊瑚礁岩、礁岩地形 觀光、潛水、生態保育 墾丁、鵝鑾鼻、貓鼻頭
東部 斷層海岸 山地逼近海洋，常見高聳海崖 觀光、部分漁港與聚落 清水斷崖、蘇花沿岸

四大海岸是概括性的區域分類，並非每個區域的每一段海岸都具有完全相同的地形。

4-6 北部：岬灣海岸

【三版共通】

自然條件：

  • 北部丘陵及山地鄰近海岸。
  • 海浪長期侵蝕不同岩層。
  • 岬角與灣澳交錯，海岸線曲折。
  • 部分灣澳具有較深水域及天然屏障。

人類利用：

基隆港等港口利用有利的灣澳條件發展航運，北部沿海也有漁港與觀光景點。

真實案例：新北市野柳

野柳是一座向海洋伸出的岬角，具有蕈狀岩、海蝕平台等景觀。

著名的女王頭屬於蕈狀岩，岩石不同部位受到不同程度的風化與侵蝕，形成特殊外形。

地理因果關係：

岩層性質與構造差異 → 海浪侵蝕及風化作用 → 形成特殊海岸地景 → 發展地質教育與觀光。

查證來源：農業部林業及自然保育署臺灣地景保育網：野柳。landscape.forest.gov.tw

易混淆提醒： 不是只要海岸線曲折，就一定能建成大型港口。還需要足夠的水深、港口腹地及交通設施。

4-7 西部：沙岸

【三版共通】

臺灣西部有較廣闊的平原，許多河川把山區泥沙帶往西部海域，再經海流、波浪搬運與堆積，形成連綿的沙岸地形。

常見景觀包括沙灘、沙洲、潟湖、魚塭與蚵架。

真實案例：臺南七股潟湖

七股潟湖是臺灣最大的潟湖，位於臺江國家公園範圍內，居民也稱其為「內海仔」。

潟湖外圍有沙洲，能阻擋部分外海波浪；潟湖中因有潮汐交換、淺水環境等條件，適合部分水產養殖。

當地常見養蚵、捕魚及生態觀光活動。

地理因果關係：

河川帶來泥沙 → 海岸沙洲形成 → 沙洲後方形成潟湖 → 潟湖較為平靜 → 發展養殖及觀光。

查證來源：臺江國家公園管理處：七股潟湖與沙洲、臺灣國家公園主題網：七股潟湖。tjnp.gov.tw+1

【翰林】另外以彰化線西蚵架、嘉義布袋魚塭等案例，介紹臺灣西部的養殖漁業。

易混淆提醒：養殖漁業不等於捕撈漁業。

比較項目 養殖漁業 捕撈漁業
主要方式 在魚塭、淺海等環境人工放養及管理水產生物 利用漁船或漁具捕捉自然水域中的水產生物
常見地點 魚塭、部分潟湖與沿海淺水區 近海、遠洋及其他可合法捕撈的水域
臺灣例子 七股養蚵、布袋魚塭 北部漁港船舶出海捕魚

4-8 南部：珊瑚礁海岸

【三版共通】

恆春半島位於臺灣南端，部分沿海水域適合珊瑚生長，長期形成珊瑚礁地形。

部分珊瑚礁受到地殼抬升與侵蝕，形成崎嶇的礁岩與隆起珊瑚礁地形。

真實案例：墾丁國家公園

墾丁國家公園擁有裙狀珊瑚礁、隆起珊瑚礁地形、石灰岩台地等多種地景。

值得注意的是，墾丁也有白砂、南灣等沙灘，因此不能把恆春半島所有海岸都當成完全相同的珊瑚礁海岸。

查證來源：墾丁國家公園管理處：自然與人文。繁體中文網

地理意義： 珊瑚礁具有生態、觀光與研究價值，但珊瑚及礁區生態也容易受到污染、踩踏、海水異常升溫等因素影響。

4-9 東部：斷層海岸

【三版共通】

臺灣東部山地靠近太平洋，受地殼運動與侵蝕等作用影響，沿岸許多地方具有陡峭的山海地形。

常見特徵：

  • 山地接近海岸。
  • 海岸平原較狹窄。
  • 部分海岸有高聳懸崖。
  • 適合大規模開發的平坦土地較少。

真實案例：花蓮清水斷崖

清水斷崖位於花蓮北部蘇花沿岸，是臺灣東部著名的海岸景觀。

地理因果關係：

板塊活動與地殼變動 → 高聳山地及斷崖地形 → 海岸平地有限 → 交通工程困難、聚落分布受限。

查證來源：太魯閣國家公園管理處：清水斷崖。taroko.gov.tw

【脈絡補充】「東部是斷層海岸」是國中課本的概括分類，不代表東部每一段海岸都是斷層直接形成的懸崖。例如宜蘭平原及部分河口仍有沙岸與沖積平原。

四、臺灣離島的形成與分布

4-10 離島的定義

【三版共通】

臺灣除了本島，周圍還有許多大小不同的島嶼，統稱為離島。

離島的形成方式不同，地形、地質與土地利用也會有所不同。

依形成原因，國中地理主要分為：

  • 大陸島
  • 火山島
  • 珊瑚礁島

4-11 三大離島類型比較

【三版共通】

類型 主要成因 地形特色 臺灣實例
大陸島 原與大陸地質構造相連，因海平面變化或地殼運動而與陸地分隔 地質與附近大陸相似 金門列嶼、馬祖列嶼
火山島 火山噴發，熔岩與火山噴發物累積形成島嶼 可能有火山岩、熔岩地形 澎湖群島、龜山島、綠島、蘭嶼
珊瑚礁島 珊瑚礁長期發育、堆積，部分受到抬升而露出海面 多具有珊瑚礁石灰岩及礁岩地形 琉球嶼、東沙島、太平島

【三版共通】臺灣離島中有許多火山島。

易混淆提醒： 火山島不代表現在一定有火山噴發。許多火山島的火山活動早已停止。

4-12 真實案例：澎湖柱狀玄武岩

【三版共通】

澎湖群島具有廣泛的玄武岩地形，桶盤嶼就是典型的觀察地點。

熔岩冷卻凝固時，因體積收縮產生裂縫，可能形成柱狀節理。

這些節理讓玄武岩呈現一根根柱子的外觀，常見多邊形截面。

【脈絡補充】柱狀玄武岩主要與熔岩冷卻收縮有關，不能解釋成「海浪把岩石切成柱子」。

查證來源：文化部文化資產局：澎湖玄武岩自然保留區。twh.boch.gov.tw

4-13 真實案例：綠島朝日溫泉

【南一／翰林】

綠島是火山島。朝日溫泉是綠島具有代表性的地熱景觀，位置接近海岸。

這個例子可結合板塊運動、火山地質及地下水循環，說明島嶼地質如何形成特殊觀光資源。

課本中的學習重點是：看到火山岩、地熱景觀時，要能聯想到地球內部的熱能與地質作用。

【脈絡補充】溫泉並不等於火山正在噴發，兩者不能直接畫上等號。

4-14 真實案例：東沙環礁國家公園

【南一】

東沙島位於南海，屬於珊瑚礁島，周圍有廣大的環礁地形。

東沙環礁國家公園於2007年成立，是臺灣第一座海洋國家公園。

【脈絡補充】環礁通常指珊瑚礁呈環狀或近環狀分布的地形，內部可以有潟湖。

東沙環礁具有珊瑚、魚類、海草床等多樣的生態資源，因此自然保育非常重要。

查證來源：內政部國家公園署海洋國家公園管理處：東沙環礁。官方亦有棘冠海星造成珊瑚受損及保育處理的紀錄。內政部國家公園署海洋國家公園管理處

【南一】課本特別引導學生討論「東沙島是否應開放一般觀光」，培養環境倫理與公共決策能力。

五、臺灣的領海與專屬經濟海域

4-15 海域權利的基本概念

【康軒／南一】

臺灣的土地以外，周圍海洋也具有資源利用、航運與安全等重要意義。

課本依《聯合國海洋法公約》介紹領海與專屬經濟海域的概念。

比較項目 領海 專屬經濟海域
英文名稱 Territorial Sea Exclusive Economic Zone, EEZ
距領海基線範圍 最遠12浬 最遠200浬
主要法律地位 沿海國享有主權，但須遵守相關國際法規則 沿海國對資源探勘、開發、養護及管理享有特定主權權利
是否等於陸地領土 法律上屬國家主權延伸的海域 不等於國家領土
主要考點 12浬 200浬

浬又稱海里，1浬約為1.852公里。

領海與專屬經濟海域示意 / 概念示意，不按實際比例繪製。專屬經濟海域自領海基線起算200浬，並非在領海外再加200浬。

查證來源：海洋委員會海巡署：執法範圍。cga.gov.tw

4-16 為什麼離島與海域權利有關？

【康軒／南一】

離島除了具有生態、居住與觀光價值，也可能影響國家海域的法律權利。

但【脈絡補充】依國際海洋法，島嶼、岩礁等不同地物具有不同的法律條件，並非每一座很小的海上地物，都一定能產生完整的200浬專屬經濟海域。

當鄰近國家的海域主張重疊，或島嶼主權存在爭議時，可能產生漁業資源、海域劃界與執法上的問題。

【康軒／南一】以釣魚臺列嶼及周邊海域爭議作為教材例子。

段考重要觀念：領海的主權、專屬經濟海域的資源權利，以及島嶼主權爭議，是三個需要分清楚的概念。

六、海岸利用與環境問題

4-17 為什麼不同海岸發展出不同產業？

【三版共通】

地理環境會影響產業選擇。

自然條件 形成的利用優勢 可能發展的產業
岩岸灣澳、水深適當、風浪較小 有利港口設置 航運、捕撈漁業
淺海、潟湖、潮汐交換 有利部分養殖活動 養殖漁業
平坦沿海、日照與水源條件合適 可利用海水製鹽 傳統鹽業
珊瑚礁生態豐富 有觀光與研究價值 生態旅遊、海洋教育
特殊火山、地質景觀 具有觀賞與教育價值 地質觀光

【脈絡補充】自然條件只是產業發展的基礎，實際能否發展，仍與法規、技術、交通、資金及市場需求有關。

4-18 臺灣海岸面臨哪些環境問題？

【康軒】明確介紹海岸侵蝕、消波塊與離岸堤等海岸工程，以及過度捕撈造成的生態問題。

【南一】重視海岸觀光、東沙環礁生態保育及開發與環境倫理。

【翰林】以潮間帶、養殖漁業及人類活動與自然環境的關係，進行生活情境探究。

環境問題 可能成因 可能影響 因應方向
海岸侵蝕 波浪作用、土砂供應變化、海岸工程等 沙灘縮減、海岸後退 保護海岸自然動態、審慎規劃工程
海洋污染 廢水、塑膠垃圾及其他污染物 破壞海洋生態與景觀 減少污染排放、淨灘、改善廢棄物管理
過度捕撈 捕撈壓力超過資源恢復能力 魚類資源減少、生態失衡 漁業管理、保育措施
珊瑚礁受損 異常高水溫、污染、踩踏等 生物多樣性受影響 珊瑚礁保育、減少人為干擾
沿海地層下陷 地下水過度抽取等 低窪地區淹水風險提高 地下水管理與供水改善

4-19 真實案例：七股沙洲退縮

【查證實例】

臺江國家公園管理處指出，七股潟湖外圍沙洲受到河川輸沙減少、季風、颱風與海浪等因素影響，部分地區曾發生沙洲退縮。

這個案例說明沙岸不是永遠固定不動的地形。

地理因果關係：

上游與沿岸土砂供應改變，加上風浪作用 → 沙洲形狀與位置改變 → 潟湖和海岸生態受到影響。

台江國家公園管理處亦曾運用現地天然廢棄竹木，嘗試減少風沙與海漂垃圾的影響。

查證來源：臺江國家公園管理處：海岸廢棄竹木再利用。tjnp.gov.tw

4-20 真實案例：臺灣西部地下水與地層下陷

【脈絡補充】

部分西部沿海地區過去因農業、養殖及其他用水需求，大量抽取地下水。

如果地下水抽取量超過自然補注量，可能使地下含水層壓密，進一步造成地層下陷。

地層下陷會使部分沿海低地更容易面臨積淹水等問題。

查證來源：立法院：地下水保育及地層下陷防治相關預算評估資料。ly.gov.tw

教學提醒： 不可簡化成「只要有魚塭就會地層下陷」。是否發生地層下陷，與地下水抽取量、地質條件、地下水補注等多種因素有關。

七、跨章延伸：從高山高麗菜看人與環境

【南一／翰林】

雖然第4章主要認識海岸與島嶼，但南一及翰林也安排山地開發的延伸閱讀，讓學生重新連結第3章「地形與土地利用」的學習重點。

4-21 為什麼有人選擇在高山種高麗菜？

【翰林】

高麗菜適合較涼爽的環境，臺灣夏季平地氣溫較高，部分農民便在較高海拔地區種植。

【脈絡補充】氣溫通常隨海拔升高而下降，因此部分高山地區在夏季可提供比較涼爽的栽培環境。

但是高山種植可能需要道路、農地整地與其他設施；若在不適合的陡坡過度開墾，會增加水土流失風險。

4-22 清境觀光與環境保育

【南一】

清境農場周邊有山地景觀與觀光產業，但地形陡峭，也有坡地災害風險。

發展觀光時，需要思考：

  • 遊客增加是否造成交通及環境負荷？
  • 大量開發民宿是否影響坡地安全？
  • 限制開發時，當地居民及業者的生計如何兼顧？

【教學統整】

自然環境有承載能力；良好的土地利用，不只是追求眼前的經濟利益，也要兼顧生態與公共安全。

第4章常見段考題型

題型1：海岸類型判斷

題目：沿海地勢平坦、海水較淺、具有大片蚵架及潟湖，最可能是臺灣哪一段海岸？

題型2：海岸地形判斷

題目：岩層軟硬交互分布，長期受到海浪侵蝕後，較堅硬的岩層可能形成什麼地形？

答案：岬角。

題型3：離島成因配對

題目：澎湖群島、金門列嶼、東沙島各屬於哪一類島嶼？

題型4：海域範圍

題目：某國依法可主張的專屬經濟海域，通常最遠可達距領海基線多少浬？

答案：200浬。

題型5：海岸環境問題

題目：七股潟湖外圍的沙洲若受到侵蝕而逐漸縮減，可能對潟湖造成什麼影響？

答案：可能減弱沙洲對部分外海波浪的屏障效果，並改變潟湖水域及其生態環境。

場景1：西部沙岸與養蚵生活 / 俯視臺南七股潟湖。前景畫沙洲，中間畫平靜的潟湖、蚵架與小漁船，後方是魚塭與陸地。用箭頭表現泥沙堆積、外海波浪及潮汐進出。 / 場景2：北部岩岸的岬角與海灣 / 畫一段由高處俯瞰的曲折海岸，較凸出的地方標示「岬角」，凹入處標示「灣澳」，並在適合的海灣畫漁港和船隻，對應海岸地形與利用。 / 場景3：東部山海相接的清水斷崖 / 畫出巨大山崖直逼太平洋，山壁中間有道路、下方是海浪。以人物或汽車比例呈現懸崖高度，強調東部海岸建設的地形限制。 / 場景4：三種離島的形成故事 / 把畫面分成三格：第一格是海水淹沒低地、留下大陸島；第二格是火山噴發形成火山島；第三格是珊瑚礁累積、露出海面形成珊瑚礁島。分別標示金門、澎湖與琉球嶼。 / 場景5：健康海洋與受破壞海洋的對照 / 左邊畫豐富珊瑚、魚群與乾淨海水；右邊畫受損珊瑚、海洋垃圾與生物減少的情境。中央放上「人類如何保護海洋？」的提問。

第3、4章跨章統整

一、地形、海岸、人類活動的完整關係

板塊運動與地殼變動 / 形成山脈、盆地與部分海岸地形 / 受到流水、海浪、風等作用 / 形成河谷、沖積平原、沙岸與其他海岸地形 / 影響聚落、交通、農業、漁業及觀光 / 土地與海洋資源開發帶來效益，也可能產生環境問題 / 以保育、監測、合理規劃與防災達成永續利用

這個流程可以作為兩章最後的綜合複習，但要提醒學生：自然環境與人類活動之間不是單向關係。人類會利用自然環境，也可能反過來改變地形與生態。

二、兩章最重要的比較整理

建議教學順序

  1. 先建立因果觀念： 板塊為何推擠？山脈如何隆起？河流如何改造地形？
  2. 再建立分類能力： 五大地形、兩種基本海岸、四大海岸區域、三種離島。
  3. 接著訓練圖表： 等高線、地形剖面、臺灣地形分布圖與海岸分布圖。
  4. 最後進入生活情境： 為什麼桃園有埤塘？七股為何適合養蚵？山坡地為何需要保育？
  5. 收束到永續議題： 人類如何在產業發展、居民需求及自然環境之間取得平衡？

給授課教師的教材審查提醒

本統整稿保留三版核心術語及考點，但部分課本內容需要注意資料解讀範圍。

例如南一「山地約47%」與翰林「山地及丘陵約70%」的統計口徑不同；翰林記載的臺灣海岸線1,341公里也不宜當成跨年份、跨測量方法都固定不變的數值。地理統計應配合其資料年度、範圍與測量方式使用。

另外，沿海地形的四區分類是國中階段的概括架構，實際海岸比課本分類更複雜。教學時應避免讓學生誤認為同一區域內所有海岸都完全一致。

對於國一學生，最重要的學習成果不是背下所有地名，而是能回答：

「這種地形為什麼形成、主要分布在哪裡、人類如何利用，以及利用後可能造成什麼影響？」

能夠用這四個問題完整解釋臺灣的地形與海岸，才算真正掌握第3、4章的核心地理觀念。
