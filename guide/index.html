新手安裝守則：Claude × GitHub × Obsidian

A one-page beginner's setup guide — three tools, three independent accounts

先看懂：三個軟體各做什麼

What each tool does — 三個軟體、三個帳號，彼此獨立，登入一個不會自動登入另一個。

Obsidian

📓 你的筆記本

筆記以一般檔案存在你電腦的資料夾裡。不需要帳號就能用。

GitHub

☁️ 雲端備份與網站發布

把資料夾備份到雲端、保留修改歷史，也能用來發布網站。需要帳號。

Claude

🤖 AI 助手

可以聊天，也能直接讀寫你的筆記資料夾、幫你整理與製作。需要帳號。

安裝順序Obsidian（最簡單）→ GitHub → Claude → 把三者串起來。照順序做，卡住時比較好找原因。

開始前先準備好

Before you start

📧 一個常用 Email

要收驗證信，註冊 GitHub 與 Claude 都會用到。

📱 一支手機

之後開「二階段驗證」，登入時要用手機確認。

🔑 密碼管理方式

三個帳號各用不同密碼。用密碼管理員，或寫在紙本、放安全的地方。

還要有：穩定網路、約 2 GB 空間；Windows 安裝時若跳出「是否允許變更」，請按「是」。Mac 安裝時若要求輸入電腦密碼，請輸入開機密碼。

Obsidian不用obsidian.md/download
GitHub要（免費方案即可）github.com/signup

1安裝 Obsidian（筆記本）

不用註冊帳號，先把筆記資料夾建立起來。

  1. 下載並安裝

    打開 obsidian.md/download。

    點 Windows 版下載 .exe，雙擊安裝，一路按「下一步」。

    點 macOS 版下載 .dmg，打開後把 Obsidian 圖示拖進「應用程式」資料夾。

  2. 建立筆記庫（Vault）

    開啟 Obsidian，選 Create new vault（建立新資料庫），畫面會問你兩件事：名稱與位置。這兩個是不同的東西：

    • 名稱（Vault name）：筆記庫自己的名字，Obsidian 會用它建立一個資料夾，例如「我的筆記」。
    • 位置（Location）：這個資料夾要放在哪裡，也就是它的上一層資料夾。

    最後的完整路徑 ＝ 位置 ＋ 名稱：

    位置名稱實際筆記資料夾
    D:\我的筆記D:\我的筆記 ✅
    D:\筆記我的筆記D:\筆記\我的筆記 ✅
    D:\我的筆記我的筆記D:\我的筆記\我的筆記 ❌ 多一層同名資料夾
    文稿我的筆記文稿/我的筆記 ✅
    文稿/筆記我的筆記文稿/筆記/我的筆記 ✅
    文稿/我的筆記我的筆記文稿/我的筆記/我的筆記 ❌ 多一層同名資料夾
    簡單記法「位置」選一個已經存在的資料夾；「名稱」填你想要的筆記庫名字，兩者不要取一樣。建好後打開那個資料夾，裡面應該直接就是筆記和 .obsidian，不會再多一層。

    位置怎麼選：

    • Windows：放在磁碟第一層，例如 D:\（沒有 D 槽就用 C:\）。不要放桌面或「文件」，這兩個常被 OneDrive 接管成同步資料夾。
    • Mac：選「文稿」。若你有開「iCloud 桌面與文稿」，改選你的使用者資料夾（家目錄），避免筆記被自動同步。

    名稱怎麼取：

    • 中英文都可以；想少踩雷就用短名字、不要有空格（路徑有空格時，用指令操作比較容易出錯）。
    • 不能包含這些字元：\ / : * ? " < > |；前後不要有空格，結尾不要是句點。
    • 不要把一個筆記庫建在另一個筆記庫裡面。
    已經有資料夾了？如果是用現成的資料夾，不要選「建立新資料庫」，改選 Open folder as vault（開啟資料夾作為資料庫），直接指到那個資料夾，就不會多出一層。
    新手先這樣做先放在本機，不要一開始就設定多台電腦同步。等你會用了，再另外學同步（見下方常見問題）。
  3. 寫第一則筆記

    左上角按「新增筆記」，輸入一些文字。

    到剛才建立的資料夾看看，應該會有一個 .md 檔，這就是你的筆記，之後 Claude 讀寫的就是它。

  4. 略過所有「登入 / Sync」提示

    Obsidian 的登入只用於付費的同步與發布服務，你現在用不到。

✅ 完成標準資料夾裡看得到你寫的 .md 檔。

2註冊 GitHub（雲端備份）

建立獨立的 GitHub 帳號，並安裝 Git 與 GitHub Desktop。

  1. 註冊帳號

    打開 github.com/signup，填入 Email、密碼、使用者名稱，完成驗證謎題。

    使用者名稱會出現在你的網址裡，取一個好記又適合公開的名字。

  2. 收驗證信

    到信箱輸入驗證碼。沒收到就看垃圾郵件匣。方案選 Free（免費）。

  3. 開啟二階段驗證（2FA）

    右上角頭像 → Settings → Password and authentication → Two-factor authentication，依指示用手機驗證 App 或通行金鑰設定。

    一定要做設定完會給你「備用碼（recovery codes）」，請下載並存在安全的地方。手機弄丟時，它是你救回帳號的唯一方法。
  4. 安裝 Git

    打開 git-scm.com/download/win 下載安裝，全部用預設選項、一路按 Next。之後 Claude Code 在 Windows 上也需要它。

    打開「終端機」（Terminal），輸入下面這行。若跳出「安裝命令列開發人員工具」，按「安裝」並等它跑完。

    git --version
  5. 安裝 GitHub Desktop

    到 desktop.github.com 下載安裝，開啟後按 Sign in to GitHub.com，瀏覽器會跳出授權，按允許即可。

✅ 完成標準GitHub Desktop 左上角顯示你的使用者名稱，而且 GitHub 帳號已開啟 2FA。

3註冊 Claude（AI 助手）

建立 Claude 帳號，安裝桌面 App；想讓 Claude 直接讀寫資料夾，再加裝 Claude Code。

  1. 註冊帳號

    打開 claude.ai，用 Google 帳號或 Email 註冊，並完成驗證。

  2. 安裝桌面 App

    到 claude.ai/download 下載 WindowsMac 版並安裝，開啟後登入。

  3. （需要時）安裝 Claude Code

    Claude Code 能讓 Claude 在你選的資料夾裡讀檔、改檔、執行指令，通常需要付費方案。桌面 App 內也有 Code 分頁可直接使用；若要用終端機版，照下面做：

    1. 先確認已裝好上一節的 Git for Windows。
    2. 按開始鈕，搜尋並打開 PowerShell，貼上：

    irm https://claude.ai/install.ps1 | iex

    打開「終端機」，貼上：

    curl -fsSL https://claude.ai/install.sh | bash

    裝完後關掉再重開終端機，輸入下面指令，跟著畫面登入：

    claude

    安裝指令可能隨版本更新，若失敗請以 官方文件 為準。

✅ 完成標準桌面 App 可以正常對話；若有裝 Claude Code，輸入 claude 能進入畫面。

4把三者串起來

Connect everything — 讓 Claude 讀你的筆記，再選擇性備份到 GitHub。

  1. 讓 Claude 打開你的筆記資料夾

    在 Claude 的 Code 分頁（或終端機 cd 進去後輸入 claude），選擇你在第 1 步建立的筆記庫資料夾。

  2. 試一句話

    對 Claude 說：「請列出這個資料夾裡有哪些筆記，並用一句話說明每一則在寫什麼。」

    Claude 要讀寫檔案時會請你允許。新手建議選「每次詢問」，看清楚再按。

  3. 寫一份「使用說明」給 Claude

    在筆記庫根目錄新增一個檔案，名稱必須是 CLAUDE.md，寫下你的規則。Claude 每次開啟都會先讀它。範例：

    # 我的規則
    - 請用繁體中文回答
    - 新筆記放在「收件匣」資料夾
    - 修改或刪除檔案前，先告訴我要改什麼
  4. （選做）備份到 GitHub

    打開 GitHub Desktop → File → Add local repository，選你的筆記庫資料夾（提示不是 repository 時，按「create a repository」）→ 填名稱 → 按 Publish repository。

    務必勾選「Keep this code private」筆記裡可能有個人資料。預設若是公開，全世界都看得到。

常見問題

Troubleshooting

收不到驗證信

先看垃圾郵件匣，等 5 分鐘後再按「重新寄送」。確認 Email 沒有打錯字。

Windows 跳出「Windows 已保護您的電腦」

確認你是從官方網站下載的，點「其他資訊」→「仍要執行」。來源不明的檔案不要執行。

Mac 說「無法打開，因為來自未識別的開發者」

從官網下載的正常不會出現。若出現：到「系統設定 → 隱私權與安全性」，往下找到被擋住的 App，按「仍要打開」。

輸入 claude 說找不到指令

先把終端機（或 PowerShell）完全關掉再重開。還是不行，就重跑一次安裝指令。

Windows 的檔名有哪些字元不能用？

檔名不能含這些字元：\ / : * ? " < > |。筆記標題如果有這些字，在 Windows 上建檔會失敗；Mac 的檔名比較寬鬆，所以跨電腦使用時要特別留意。

Mac 的筆記標題有「:」「?」，換到 Windows 會怎樣？

Windows 不允許檔名含 \ / : * ? " < > |，這類檔案可能無法同步。若之後要兩台電腦共用，筆記標題一開始就避開這些字元。

想在兩台電腦用同一個筆記庫（同步）怎麼辦？

這是進階主題，建議先在一台電腦用熟再說。常見做法：
• iCloud / OneDrive：免費，但 Windows 端要設成「永遠保留在此裝置」，且兩台不要同時編輯。
• Obsidian Sync：官方付費同步，最穩。
• GitHub：適合備份與版本紀錄，但不是即時同步。
不要把 Git 倉庫放進 iCloud 或 OneDrive 的同步資料夾。

Claude 說要執行某個指令或刪除檔案，我該按允許嗎？

先看它說要做什麼。不確定就問它「這個指令會做什麼？」，看懂再允許。刪除與覆蓋這類動作，建議先把重要資料另外備份一份。

安全守則

Golden rules — 新手最容易出事的地方。

✅ 一定要做

  • GitHub 與 Claude 都開二階段驗證
  • 備用碼存在離線、安全的地方
  • 三個帳號用不同密碼
  • GitHub 存筆記一律選 Private
  • 只從官方網站下載軟體
  • 重要資料先備份，再讓 AI 動手

🚫 千萬不要

  • 把密碼、金鑰（API key）、Token 貼進聊天或筆記
  • 把含個資的筆記推到公開的 GitHub
  • 沒看清楚就按「允許」刪除或覆蓋
  • 兩台電腦同時編輯同一個筆記庫
  • 點來路不明的「安裝連結」
