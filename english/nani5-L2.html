本課主題速覽

🟦 Dialogue｜Henry 與 Lucy：體育課跑完 800 公尺

體育課剛跑完 800 公尺，Lucy 的腿又燙（burning）又痠（sore），Henry 只是有點口渴。Henry 參加過好幾次趣味路跑，最愛 Costume Run（穿成長頸鹿、飛機、巨大蟲子）；他阿姨在日本跑過 Sumo Run，而臺灣也有舉辦（are held）。Henry 不久要在臺中參加 Zombie Run，邀 Lucy 同行——Lucy：「老實說，我不太會跑，讓我想想。」

🟩 Reading｜Fun Runs：runDisney 與 Zombie Run

趣味路跑在世界各地都有舉辦，大多不到 5 公里（3 英里）。runDisney：跑者穿迪士尼裝，出發（set off）後頭頂有煙火，迪士尼角色在人行道上歡呼、送飛吻，完賽被頒一面獎牌當獎品。Zombie Run：通常在萬聖節前後舉辦，跑者可能被殭屍「殺死」，沿路聽得到尖叫，要保住生命旗才能活著；旗子全被拿走就出局。

🟧 Grammar｜被動語態全時態

課本 Grammar A：現在式／過去式被動 is/was + p.p.（by…）；Grammar B：助動詞被動 will / should / can + be + p.p.；Grammar C：現在完成式被動 have/has been + p.p.。另補段考高頻：主動改被動、不及物動詞（happen、appear）不能被動、By whom…? 與 be made to V。

課文逐句精講（Dialogue + Reading）

🔍 句構顏色對照： 主詞 S　動詞 V　受詞 O　補語 C　修飾語

Dialogue 場景在體育課：Henry 和 Lucy 剛跑完 800 公尺正在休息，聊起各種趣味路跑。Reading〈Fun Runs〉介紹兩種最受歡迎的趣味路跑——runDisney 與 Zombie Run，全文大量使用各種時態的被動語態。以下英文逐字取自課本。

💬 Dialogue｜Henry 與 Lucy 的對話（after an 800-meter run in PE class）
▶LucyI’m so tired. My legs are burning and sore. How about you?
我好累。我的腿又燙又痠。你呢？
🔍 句構分析 ①IS ’mV so tiredC
②My legsS areV burning and soreC（形容詞）
③How about you?那你呢？
burn (v.) 發燙 → burning；sore 疼痛的。📊 復興、太保、桃子腳、三民 4 校考 burning and sore（翻譯填空常見）。
▶HenryI’m OK but just a little thirsty.
我還好，只是有點口渴。
🔍 句構分析 ①IS ’mV OK but just a little thirstyC
thirsty 口渴的（📊 5 校考）。a little + adj. 有一點……。
▶HenryRunning is my favorite sport. I’ve been to several fun runs.
跑步是我最喜歡的運動。我參加過好幾次趣味路跑。
🔍 句構分析 ①RunningS（動名詞） isV my favorite sportC
②IS ’ve been toV（經驗） several fun runsO
動名詞當主詞 → 單數動詞 is。have been to 去過（L1 現在完成式）。several 幾個。
▶LucyI’ve heard about fun runs. What’s so special about them?
我聽說過趣味路跑。它們有什麼特別的？
🔍 句構分析 ①IS ’ve heard aboutV fun runsO
②WhatS ’sV so specialC about them關於它們
hear about 聽說。What’s special about…? ……有什麼特別？
▶HenryThere are different kinds of fun runs, but I love Costume Runs the most.
趣味路跑有很多種，不過我最愛變裝路跑。
🔍 句構分析 ①There are有 different kinds of fun runsS
②but連接詞 IS loveV Costume RunsO the most最
kinds of 種類。costume 服裝、扮裝（📊 3 校考）；Costume Run 變裝路跑。
▶HenryRunners dress up in funny costumes, like a giraffe, an airplane, or even a giant bug.
跑者會穿上好笑的服裝，像是長頸鹿、飛機，甚至是巨大的蟲子。
🔍 句構分析 ①RunnersS dress upV in funny costumes穿著 like a giraffe, an airplane, or even a giant bug舉例
dress up in + 服裝；dress up as + 角色。airplane＝plane；bug 小蟲子（📊 段考常考）。like＝例如。
▶LucyNice. Are Costume Runs only popular in Taiwan?
真不錯。變裝路跑只在臺灣受歡迎嗎？
🔍 句構分析 ①Nice.讚
②AreV Costume RunsS only只 popularC in Taiwan地點
be popular in + 地方 在……受歡迎。
▶HenryNo, they’re also popular in other countries.
不，它們在其他國家也很受歡迎。
🔍 句構分析 ①No回答 theyS ’reV also也 popularC in other countries地點
also 放 be 動詞後面。
▶HenryMy aunt ran in a Costume Run in Japan. It was called the Sumo Run.
我阿姨在日本跑過一場變裝路跑，它叫做相撲路跑。
🔍 句構分析 ①My auntS ranV（過去式） in a Costume Run在比賽中 in Japan地點
②ItS was calledV（過去式被動） the Sumo RunC
be called 被稱為 → 被動語態。run–ran–run。課本補充：Sumo Run 是日本為 2016 年熊本地震災後籌款而創立。
▶HenryLet me show you some pictures.
我給你看一些照片。
🔍 句構分析 ①LetV（祈使） meO show you some pictures受詞補語（原形 V）
let + O + 原形 V。show + 人 + 物。
▶LucyThe Sumo costumes are so large! Everyone looks so funny.
相撲裝好大件！每個人看起來都好好笑。
🔍 句構分析 ①The Sumo costumesS areV so largeC
②EveryoneS（單數） looksV（連綴） so funnyC
everyone 視為單數 → looks。look + adj. 看起來（連綴動詞不用被動）。
▶HenrySumo Runs are also held in Taiwan.
臺灣也有舉辦相撲路跑。
🔍 句構分析 ①Sumo RunsS are also heldV（現在式被動） in Taiwan地點
be held 被舉辦（hold–held–held）——呼應課名 Fun Runs Are Held All Around the World。
▶HenryI’ll try one some day in the future.
將來某天我要試試看。
🔍 句構分析 ①IS ’ll tryV oneO（＝a Sumo Run） some day in the future將來某天
one 代替 a Sumo Run。some day＝someday。
▶LucyWow, that will be a very special experience.
哇，那會是很特別的經驗。
🔍 句構分析 ①Wow感嘆詞 thatS will beV a very special experienceC
experience 指「一次經歷」時可數（a special experience）。
▶HenryYes. I also want to try other fun runs, like the Light Run or the Zombie Run.
是啊。我也想試試其他趣味路跑，像是螢光路跑或殭屍路跑。
🔍 句構分析 ①Yes.回答
②IS also也 wantV to try other fun runsO like the Light Run or the Zombie Run舉例
light (n.) 光（📊 段考常考）。課本補充：Light Run 是夜晚戴著螢光棒跑。
▶LucyThe Zombie Run sounds very interesting.
殭屍路跑聽起來很有趣。
🔍 句構分析 ①The Zombie RunS soundsV（連綴） very interestingC
sound + adj. 聽起來……（連綴動詞，不用被動）。
▶HenryYeah. I’ll take part in the Zombie Run soon in Taichung.
對啊。我不久就要在臺中參加殭屍路跑。
🔍 句構分析 ①Yeah.回答
②IS ’ll take part inV the Zombie RunO soon不久 in Taichung地點
take part in 參加（＝join）。soon 不久；很快地。
▶HenryWould you like to join me?
你要跟我一起去嗎？
🔍 句構分析 ①Would助動詞 youS likeV to join meO
Would you like to + V? 禮貌的邀請。
▶LucyTo be honest, I’m not a great runner. Let me think about it.
老實說，我不太會跑步。讓我考慮一下。
🔍 句構分析 ①To be honest老實說 IS ’m notV a great runnerC
②LetV meO think about it受詞補語（原形 V）
to be honest 老實說；honest 誠實的（h 不發音 → an honest boy，📊 3 校考）。run → runner（重複 n）。課本理解題：Lucy 說 Let me think about it 是因為她不太會跑。
📗 Reading〈Fun Runs〉¶1｜什麼是趣味路跑
▶Fun runs have been held all around the world.
趣味路跑在世界各地都有舉辦。
🔍 句構分析 ①Fun runsS have been heldV（現在完成式被動） all around the world世界各地
have been + p.p. 現在完成式被動——南一段考最高頻文法（6 校 16 題）。
▶Most of them are less than 5 kilometers (3 miles) long.
它們大多數不到 5 公里（3 英里）長。
🔍 句構分析 ①Most of themS areV less than 5 kilometers (3 miles) longC
less than 少於。mile 英里（📊 段考常考）。數字 + 單位 + long 表長度。
▶Two of the most popular fun runs are the runDisney and the Zombie Run.
最受歡迎的趣味路跑中，有兩個是 runDisney 和殭屍路跑。
🔍 句構分析 ①Two of the most popular fun runsS areV the runDisney and the Zombie RunC
one / two of the + 最高級 + 複數名詞。

▶Lovers of Disney movies will love the runDisney because they can wear their favorite Disney costumes.
喜愛迪士尼電影的人會愛上 runDisney，因為他們可以穿上最喜歡的迪士尼服裝。

②because原因 theyS can wearV their favorite Disney costumesO

▶After the runners set off, they see colorful fireworks above them in the sky.
跑者出發後，會看到頭頂的天空中有繽紛的煙火。

▶As they go happily through the Disney parks, Disney characters cheer and blow them kisses from the sidewalk.
當他們開心地穿越迪士尼樂園時，迪士尼角色們在人行道上歡呼，並對他們送飛吻。
🔍 句構分析 ①As they go happily through the Disney parks時間子句 Disney charactersS cheer and blowV them間接受詞 kisses直接受詞 from the sidewalk從人行道上
blow sb kisses＝blow kisses to sb 送飛吻（blow–blew–blown，📊 段考常考）。sidewalk 人行道（📊 5 校考）。character 角色（📊 4 校考）。
▶When the runners finish the race, a lovely Disney medal is given to them as a prize.
跑者跑完比賽時，一面漂亮的迪士尼獎牌會頒給他們當作獎品。
🔍 句構分析 ①When the runners finish the race時間子句 a lovely Disney medalS is givenV（現在式被動） to them對象 as a prize作為獎品
give + 物 + to 人 的被動：物 + is given + to 人。lovely 這裡＝漂亮的。medal 獎牌、prize 獎品（📊 各 4、5 校考）。
📗 Reading ¶3｜Zombie Run
▶Zombie Runs are usually held around Halloween.
殭屍路跑通常在萬聖節前後舉辦。
🔍 句構分析 ①Zombie RunsS are usually heldV（現在式被動） around Halloween時間
頻率副詞放 be 動詞後面：are usually held。
▶They are exciting because runners can be killed by zombies.
它們很刺激，因為跑者可能會被殭屍「殺死」。
🔍 句構分析 ①TheyS areV excitingC
②because原因 runnersS can be killedV（助動詞被動） by zombies行為者
can be + p.p.。exciting 令人興奮的（事物）≠ excited（人）。課本理解題：被「殺死」＝出局（out of the game）。
▶When they are running, hungry zombies hunt for them everywhere.
他們在跑的時候，飢餓的殭屍到處追獵他們。
🔍 句構分析 ①When they are running時間子句 hungry zombiesS hunt forV themO everywhere到處
hunt (for) 追獵（📊 段考常考）。
▶Cries and screams can be heard all along the way.
一路上都聽得到哭喊聲和尖叫聲。
🔍 句構分析 ①Cries and screamsS can be heardV（助動詞被動） all along the way一路上
scream 尖叫（📊 3 校考）。hear–heard–heard。
▶To stay alive, the runners have to keep their life flags.
為了活下來，跑者必須保住他們的生命旗。
🔍 句構分析 ①To stay alive目的 the runnersS have to keepV their life flagsO
stay alive 活下來；alive 活著的（不放名詞前，📊 段考常考）。flag 旗子（📊 3 校考）。
▶The zombies do their best to pull off the flags.
殭屍們盡全力扯下旗子。
🔍 句構分析 ①The zombiesS doV their bestO to pull off the flags目的
pull off 扯下（📊 3 校考）。do one’s best to V（L1 也學過）。
▶If a runner’s flags are all taken away, the runner is out.
如果一位跑者的旗子全被拿走，那位跑者就出局了。
🔍 句構分析 ①If a runner’s flags are all taken away條件子句（被動） the runnerS isV outC（出局）
take away 拿走 → 被動 be taken away（take–took–taken，📊 段考常考）。all 放 be 動詞後。
▶However, if the runners don’t lose all their flags, they get a medal.
不過，如果跑者沒有失去全部的旗子，他們就能得到一面獎牌。
🔍 句構分析 ①However然而 if the runners don’t lose all their flags條件子句 theyS getV a medalO
However, 然而（後面加逗號）。if 子句用現在式。

核心句型文法解析
👆 點擊每個句型標題，展開「公式 + 例句 + 常見錯誤 + 會考／段考重點」。
句型一｜Grammar A：被動語態基本句：be + p.p. (+ by 行為者)＋現在式被動▼
主動：S + V + O 被動：O + be + p.p. (+ by S) 現在式被動：am / is / are + p.p.

當「動作的接受者」比「做動作的人」更重要時用被動。be 動詞決定時態與單複數，p.p. 決定動作。行為者不重要、不知道或是一般人（people, they）時，by…可省略。

Sumo Runs are also held in Taiwan.
臺灣也有舉辦相撲路跑。（課文）
A lovely Disney medal is given to them as a prize.
一面漂亮的迪士尼獎牌被當作獎品頒給他們。（課文，省略 by…）
English is spoken all over the world.
全世界都說英語。（課本 Grammar A）
✗ English speaks in many countries.（物當主詞要被動）✗ The runners are chase by…（要用 p.p.）✗ Fun runs is held…（複數 → are）
段考常考 English is spoken…。先問自己：「主詞是做動作的，還是被做的？」被做的 → be + p.p.
句型二｜Grammar A：過去式被動 was / were + p.p.＋主動改被動三步驟▼
① 主動的受詞 → 被動的主詞 ② 動詞 → be + p.p.（be 動詞跟著原句時態與新主詞變化） ③ 主動的主詞 → by + 受格（可省略）

過去式被動用 was / were + p.p.。改寫時最常錯在「be 動詞沒跟新主詞一致」和「代名詞沒改成受格」。

主動被動
A girl found my wallet.My wallet was found by a girl.
They gave each runner three flags.Each runner was given three flags.
He moved my notebooks.My notebooks were moved by him.
It was called the Sumo Run.
它叫做相撲路跑。（課文）
The house was bought by my parents last year.
這房子是我爸媽去年買的。（課本 Grammar A）
This apartment was bought by Mr. and Mrs. Lin.
這間公寓是林先生和林太太買的。
✗ My notebooks was moved.（複數 → were）✗ …by she（by 後要用受格 her）✗ The cake was ate.（eat 的 p.p. 是 eaten）
段考常考去式被動。改寫題記得：時態不變，只換句型。
句型三｜Grammar B：未來式與助動詞被動：will be / be going to be / can be + p.p.▼
S + will be + p.p. S + am/is/are going to be + p.p. S + can / must / should + be + p.p.

助動詞後面一律接原形 be，再接 p.p.。否定：will not be / can’t be + p.p.；問句：Will / Can + S + be + p.p.…?

Runners can be killed by zombies.
跑者可能被殭屍「殺死」。（課文）
Dinner will be cooked by Dad.
晚餐將由爸爸煮。（課本 Grammar B）
Cries and screams can be heard all along the way.
一路上都聽得到哭喊和尖叫。（課文）
A new bridge is going to be built here.
這裡將要蓋一座新橋。
This question can’t be answered by many students.
這題很多學生都答不出來。
✗ will held ✗ can heard ✗ will is held ✗ can be hear
6 校考助動詞／未來式被動（12 題）。看到 will / can / must 後面要先放 be，再放 p.p.。
句型四｜Grammar C：現在完成式被動：have / has been + p.p.▼
S + have / has been + p.p. (+ since / for …) S + haven’t / hasn’t been + p.p. … yet. Have / Has + S + been + p.p. …?

把「現在完成式 have + p.p.」和「被動 be + p.p.」結合：have / has + been + p.p.。常配 since / for / already / yet。

Fun runs have been held all around the world.
趣味路跑在世界各地都有舉辦。（課文）
These shoes have been worn for many years.
這雙鞋已經穿了很多年。（課本 Grammar C）
A lot of money has been donated to charity since the first race.
自從第一場比賽以來，已經有很多錢捐給慈善機構。
This piano hasn’t been played since 2020.
這架鋼琴從 2020 年起就沒人彈過。
All the tickets have already been sold out.
所有的票都已經賣光了。
✗ has donated（錢是被捐 → has been donated）✗ have been sell ✗ has been +原形 ✗ was donated since…（since 要配完成式）
南一最高頻文法：6 校 16 題考現在完成式被動。判斷順序：since / for / already / yet → 完成式；主詞是被做的 → 加 been。
句型五｜被動易錯點：不及物動詞、連綴動詞、By whom…?、be made to V▼
不及物動詞（happen, appear, die, arrive）→ 不能被動 連綴動詞（taste, smell, look, sound）→ 不能被動 By whom + be + S + p.p.? 使役／感官動詞改被動：be made / seen / heard + to V

不是所有動詞都能改被動：沒有受詞的動詞（不及物）與連綴動詞都不行。另外，make / see / hear + O + 原形 V 改被動時，要補回 to。

錯誤正確
The accident was happened.The accident happened.
The cake is tasted good.The cake tastes good.
Who were the pictures taken by?（可）By whom were the pictures taken?
They made us run. → We were made run.We were made to run.
They appeared on many TV programs.
他們上過很多電視節目。（L1 課文；✗ were appeared）
By whom were these medals made?
這些獎牌是誰做的？
This dress has to be washed.
這件洋裝必須洗一洗。（物當主詞 → 被動）
✗ was happened ✗ is tasted delicious ✗ were made run ✗ By who were…（介系詞後用 whom）
段考常考 taste 不用被動、has to be washed；本課陷阱題多半出在「不及物動詞誤用被動」。
