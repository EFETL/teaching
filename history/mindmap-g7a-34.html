第 3 課　大航海時代臺灣原住民與外來者

一句話主題： 17 世紀的臺灣原住民族面對荷蘭、西班牙與鄭氏政權，透過反抗、合作及文化交流回應外來勢力，原有的生活也逐漸改變。

學習目標

學完本課，學生應能：

  1. 說明原住民族在外來政權抵達前的生活與經濟活動。
  2. 比較荷蘭、西班牙與鄭氏政權和原住民族互動的方式。
  3. 解釋麻豆社事件、大肚王反抗與地方會議的歷史意義。
  4. 分析貿易、宗教、教育與土地拓墾對原住民族的影響。
  5. 從原住民族的立場思考：為什麼有些部落選擇合作，有些選擇反抗？

一、歷史背景：外來者抵達前的臺灣

1. 臺灣原住民族原本如何生活？

【三版共通】

在歐洲人來臺以前，臺灣已經有許多原住民族群居住。不同族群擁有自己的語言、文化、信仰、社會組織和生活方式。

生活面向 主要特色
社會組織 以部落為重要生活單位，部分部落有頭目、長老等領導者
農業 種植小米、芋頭等作物，部分地區採取游耕
狩獵 利用弓箭、標槍等工具捕獵梅花鹿等動物
漁撈 在沿海、河川等水域捕魚、採集水產
宗教 許多族群具有祖靈、自然神靈等傳統信仰
貿易 在歐洲人抵達前，已與外來商人交換物資

【南一】 特別提到原住民族與漢人、日本商人已有貿易往來，以及西拉雅族祭祀阿立祖的傳統信仰。

【延伸補充】 不能把臺灣所有原住民族的生活都說成完全相同。平原、山區、沿海的自然環境不同，各族的社會組織與生產方式也有差異。

2. 什麼是游耕？

【三版共通】

游耕是一種因應土地與環境條件的耕作方式：

清理土地 / 焚燒植被 / 播種耕作 / 地力下降後移耕

焚燒後的灰燼可提供土壤養分。土地使用一段時間後，若地力不足，就改到其他適合耕作的地方。

【易混淆】游耕不等於到處流浪，也不代表原住民族沒有農業技術。

3. 為什麼外來者會來臺灣？

【三版共通】

臺灣位於東亞海上交通的重要位置，周邊海域連結中國、日本與東南亞。

16、17 世紀，東亞海上貿易日益興盛，外來勢力希望利用臺灣取得商業利益、建立據點與擴張影響力。

主要的外來政權有：

  • 荷蘭人： 以臺灣南部為主要據點，發展貿易並控制周圍部落。
  • 西班牙人： 在臺灣北部建立據點，進行貿易與天主教傳教。
  • 鄭氏政權： 以臺灣作為政權基地，推動屯墾、農業與文教發展。

這三股勢力來臺後，原住民族開始面對新的統治、貿易和土地壓力。

三、荷蘭人與原住民族的互動

1. 武力征服：利用部落間的關係

【三版共通】

荷蘭人為了擴張統治範圍，對不願服從的部落採取軍事行動。

然而，荷蘭在臺灣的兵力有限，因此也利用原有的部落關係，與部分部落結盟，再共同攻打其他部落。

以麻豆社事件為例 / 麻豆社與荷蘭勢力發生衝突 / 1629 年，麻豆社襲擊荷蘭士兵 / 荷蘭聯合新港社出兵 / 1635 年，荷蘭取得增援後攻打麻豆社 / 麻豆社戰敗並接受荷蘭統治 / 荷蘭鞏固在臺灣南部的統治

重要人物與部落

名稱 所屬或身分 在事件中的角色
荷蘭聯合東印度公司 荷蘭商業殖民組織 派遣軍隊、擴張統治
新港社 臺南地區西拉雅族部落 與荷蘭結盟，協助攻打麻豆社
麻豆社 臺南地區西拉雅族重要部落 抗拒荷蘭統治，遭軍事攻擊

【南一】 提供更完整的事件過程：1629 年，63 名荷蘭士兵在麻豆社協助下執行任務，回程渡河時遭到突襲；1635 年荷蘭才進行大規模報復。

【翰林】 強調 1635 年麻豆社之役，是荷蘭奠定南臺灣統治的重要軍事行動。

【段考重點】新港社與麻豆社都屬西拉雅族，卻採取不同的對荷立場。相同族群不代表一定有相同的政治選擇。

2. 間接統治：地方會議

【三版共通】

荷蘭人不可能直接管理臺灣每一個部落，因此利用部落長老協助統治。

這種方式稱為「間接統治」。

荷蘭長官 / 代表殖民政權 / 各社長老 / 管理原有部落 / 年度「地方會議」 / 荷蘭長官：授予象徵權威的藤杖、發布命令、裁決紛爭。 / 原住民長老：宣誓效忠、報告部落狀況、協助執行政令。

間接統治的結果：

對象 可能得到的好處 付出的代價或限制
荷蘭政權 減少直接治理所需的人力，擴大控制範圍 仍須依賴部落領袖的合作
合作部落 可能獲得軍事保護、貿易機會、政治支持 必須服從荷蘭政令，自治空間受限制
反抗部落 可表達不願接受統治的立場 可能遭到軍事鎮壓

【康軒】 延伸閱讀特別描寫地方會議後的宴飲、部落代表接受藤杖，以及部分部落因結盟而獲得安全保障。

【易混淆】地方會議並不是現代民主制度的議會。原住民長老雖然參與會議，卻不是與荷蘭長官處於平等的政治地位。

3. 經濟活動：鹿皮貿易帶來的變化

【三版共通】

梅花鹿原本是部分平埔族群的重要生活資源，可提供肉食、鹿皮及其他材料。

荷蘭人來臺後，鹿皮成為重要出口商品，貿易規模擴大。

原住民 / 狩獵、取得鹿皮 / 漢人商人 / 交換布、鹽、鐵器 / 荷蘭商人 / 收購與出口鹿皮 / 這是課本描述的主要貿易模式，不代表所有交易都必須經過漢人商人。

事件因果關係：

鹿皮的國際需求增加 → 捕鹿活動增加 → 梅花鹿大量減少，加上土地開墾造成棲地縮小 → 原住民族既有的經濟與文化生活受到衝擊。

【南一】 特別補充漢人移民帶來農業技術、開墾土地，使部分原住民族逐漸改變生活方式。

【翰林】 課後閱讀〈從繁盛、絕跡到重生——臺灣梅花鹿〉，從生態角度探討過度獵捕及後來的復育工作。

4. 宗教與教育：基督教和新港文書

【三版共通】

荷蘭傳教士在統治區域建立教堂、學校，推廣基督教。

為了讓原住民族理解教義，傳教士使用羅馬字母拼寫當地語言，教導族人閱讀、書寫並翻譯宗教教材。

最著名的例子，就是與西拉雅族新港社密切相關的新港文字與新港文書。

nicecasio.pixnet.net / 新港文書：可觀察羅馬字母與漢字如何共同記錄清代的土地交易。

概念 正確認識
新港文字 以羅馬字母拼寫西拉雅語等當地語言的書寫形式
新港文書 使用這類文字留下的契約及其他文件
番仔契 清代對部分原住民土地契約的歷史俗稱
歷史價值 研究原住民族語言、土地權利、交易與文化變化

傳教活動主要發生在荷蘭統治期間，但部分族人在清代仍使用這套書寫方式處理土地交易，說明文字的影響超越了荷蘭統治時期。

【延伸補充】新港文書不是全部由傳教士書寫，也不一定都是雙語契約；有些文書只有羅馬字母書寫的族語。

真實文物查證： 國史館臺灣文獻館典藏清乾隆二十一年（1756）的「灣裡社大馬役賣盡根契」，記錄原住民族與漢人的土地交易，可看到漢字與羅馬字拼寫的文字。來源：國史館臺灣文獻館〈新港文書〉。國史館-臺灣文獻館

【段考重點】看到「羅馬字母、原住民族語言、土地契約、荷蘭傳教士」等線索，應聯想到新港文書，而不是直接認為這份契約一定寫於荷蘭統治時期。

四、西班牙人與臺灣北部原住民族

1. 軍事行動與宗教傳播

【三版共通】

西班牙人在雞籠、淡水一帶建立據點，也曾以武力迫使當地部落歸順。

同時派遣傳教士，建立教堂，推廣天主教。部分原住民接受天主教信仰，也有人學會西班牙語。

【南一】 特別介紹基隆和平島的聖薩爾瓦多城、諸聖教堂，以及西班牙政權與部落關係的變化。

【翰林】 強調部分北部原住民學會西班牙語，並介紹西班牙人命名的「三貂角」。

【康軒】 特別指出北部原住民也曾反抗西班牙政權，並非全部自願接受統治。

2. 荷蘭與西班牙比較

比較項目 荷蘭人 西班牙人
主要活動區域 臺灣南部 臺灣北部
重要據點 大員、熱蘭遮城等 雞籠、淡水等

【易混淆】天主教也是基督教的一個主要分支。 因此不能說「荷蘭人信基督教，西班牙人不信基督教」。國中歷史課本是在區分荷蘭的基督新教與西班牙的天主教傳教活動。

五、中部的大肚王：跨部落聯盟與反抗

1. 大肚王是什麼？

【三版共通】

17 世紀臺灣中部，曾有一個以大肚地區為重要中心的跨部落勢力。

課本一般稱為「大肚王」或「大肚王國」。

【延伸補充】

大肚王的勢力與今日臺中、彰化、南投部分地區有關。

其聯盟包含後來被分類為拍瀑拉族（又譯巴布拉族）、巴布薩族、巴宰族等不同族群的部落。

因此，大肚王國不是單一民族建立的現代國家，而較適合理解為具有共同領袖與政治聯繫的跨族群部落聯盟。

歷史文獻與研究對聯盟的具體規模、疆界及權力結構仍有討論，不宜將其畫成界線完全固定的現代國家。

來源：國立自然科學博物館〈尋找中部平埔族的祖先〉、臺灣原住民族事典〈大肚王〉。web3.nmns.edu.tw+1

2. 大肚王為什麼與荷蘭、鄭氏衝突？

時期 衝突背景 結果
荷蘭時期 荷蘭向中部擴張統治，與大肚王勢力發生衝突 荷蘭軍事進攻，使聯盟部分部落接受其管轄
鄭氏時期 鄭軍拓墾、土地壓力和勞役負擔增加 大肚王勢力反抗，鄭氏派兵鎮壓，造成重大傷亡

【康軒】 強調大肚王在荷蘭擴張過程中逐漸喪失獨立地位。

【南一】 特別指出鄭氏軍隊的屯墾活動與沉重勞役，是促成衝突的重要原因。

【翰林】 強調大肚王勢力經過鄭氏鎮壓後逐漸衰微。

【段考重點】大肚王不是只有反抗鄭氏政權，也曾與荷蘭勢力發生戰爭。

六、鄭氏政權與原住民族

1. 鄭氏政權為什麼積極拓墾？

【三版共通】

鄭氏在臺期間，軍隊及漢人移民需要大量糧食。

為了供應軍民生活，鄭氏政權推動農業開發，派遣官兵到各地屯墾。

但新的耕地不斷增加，也使原住民族原有的生活空間受到壓迫。

屯墾與衝突的因果關係 / 軍隊與移民增加，糧食需求擴大 / 政府鼓勵農業開發、派兵屯墾 / 部分拓墾活動侵入原住民族生活領域 / 原漢衝突增加，部分部落起兵反抗 / 鄭氏派兵鎮壓，部落遭受傷亡

【康軒】 提到鄭氏政權曾強調拓墾時不可侵奪原住民土地。但實際上，隨著拓墾擴大，仍發生嚴重衝突。

【易混淆】政府曾宣示避免侵犯土地，不代表實際執行一定能保障原住民族的土地權益。歷史上要分清楚政策宣示與執行結果。

二、清帝國為什麼將臺灣納入版圖？

1. 鄭氏政權結束後的臺灣棄留爭議

【三版共通】

1683 年，鄭氏政權投降。清廷雖然已經取得臺灣的控制權，卻對是否保留臺灣產生爭論。

當時主要有兩種意見：

立場 主張放棄臺灣的大臣 主張保留臺灣的施琅
地理看法 臺灣遠離中國大陸，治理困難 臺灣位於東南沿海的重要位置
經濟看法 設官駐軍會增加財政負擔 臺灣土地肥沃、物產豐富
軍事看法 擔心臺灣成為反清勢力據點 保留臺灣可以保護中國東南沿海
政策主張 放棄臺灣，減少負擔 保留臺灣，建立統治制度

最後康熙皇帝採納施琅的主張，於 1684 年正式將臺灣納入清帝國版圖。

【南一】 以臺南大天后宮的石碑史料，讓學生理解施琅平定臺灣後的主張。

【翰林】 利用清初臺灣地方風俗圖，說明當時臺灣已有原住民部落、漢人聚落與前代政權的建築。

2. 施琅是誰？

施琅原本曾是鄭成功的部將，後來改為清帝國效力。

他率領清軍擊敗鄭氏勢力，並向朝廷主張保留臺灣。

【段考重點】施琅在本課的關鍵身分有兩個：

  • 率領清軍攻取臺灣的重要將領。
  • 主張保留臺灣、重視海防戰略的官員。

【易混淆】1683 年與 1684 年不同。

1683 年是鄭氏政權投降；1684 年是清廷正式設官治理、將臺灣納入版圖。

三、清帝國初期的治臺政策：「為防臺而治臺」

1. 什麼是「為防臺而治臺」？

【三版共通】

清帝國擔心臺灣再次成為反清勢力的基地，因此統治初期重視限制、隔離與防範動亂。

「為防臺而治臺」可以簡單理解為：

清廷管理臺灣，首先考慮的是如何防止臺灣發生威脅統治的動亂。

其主要措施有兩項：

為防臺而治臺 / 防止反清活動，維持清廷統治 / 渡臺禁令 / 限制漢人移民來臺 / 劃界封山 / 限制跨越番界開墾

2. 渡臺禁令

【三版共通】

清帝國統治臺灣初期，為限制漢人移民來臺，要求渡海者申請證照，並在部分時期限制攜帶家眷。

但福建、廣東人口增加，土地與謀生機會不足，臺灣又有不少可開墾土地，許多人仍冒險渡海。

因此，政策出現以下情形：

政策目的 實際結果
限制移民來臺 許多人仍冒險偷渡
避免形成反清勢力 臺灣仍不斷出現民變與社會衝突
限制攜眷 早期漢人移民男女人口比例失衡

【康軒、翰林】 特別介紹「羅漢腳」與「有唐山公，無唐山媽」。

為什麼出現「有唐山公，無唐山媽」？

這句俗諺的意思是：早期從中國大陸來臺的男性移民較多，女性相對較少。

因為渡臺禁令及移民條件限制，部分漢人男性與平埔族女子結婚，促成原漢之間的家庭與文化交流。

什麼是羅漢腳？

清代臺灣社會中，沒有家眷、缺乏固定職業或穩定生活依靠的單身男性，有時被稱為「羅漢腳」。

清廷官員常將這類人口視為可能造成治安問題的群體。

【易混淆】

  • 「有唐山公，無唐山媽」不表示當時完全沒有女性從中國大陸移民臺灣。
  • 渡臺禁令並不是 1684 年到廢除前都完全相同、毫無變動。
  • 羅漢腳不等於所有男性移民，更不能說單身男性一定會犯罪。

【康軒】 附有禁令時緊時鬆的史料與年表，正好說明法律規定與實際執行情況可能不同。

3. 劃界封山與番界

【三版共通】

清廷為了減少漢人與原住民族的衝突，並方便管理，在部分區域設立邊界，限制漢人越界開墾。

這條用來區隔不同生活與管理區域的界線，稱為「番界」。

番界可能使用：

  • 界碑
  • 土堆（土牛）
  • 土牛溝
  • 其他天然或人工界線

番界示意圖（非實際地圖） / 番界並非各地一致、固定不動的直線。實際位置與形式會因時間、地區及官府管理情況而不同。

為什麼番界不斷改變？

【三版共通】

清廷雖然限制越界，但漢人移民持續增加，耕地需求擴大，因此違規越界開墾的情況不斷發生。

其因果關係如下：

漢人移民增加 → 耕地需求增加 → 越過番界開墾 → 原住民族生活空間縮小 → 原漢衝突加劇 → 官府重新劃定部分界線。

【翰林】 特別說明番界與限制原漢通婚等政策，並利用《番社采風圖》的守隘畫面介紹番界附近的巡守活動。

【易混淆】清廷設立番界，不能簡化為「完全是為了保護原住民族」。除了減少衝突，清廷也希望控制人口、土地與邊疆秩序。

4. 真實古物：土牛民番地界碑

【三版共通、網路查證】

臺中市石岡區土牛國小保存清代的「土牛民番地界碑」。

石碑立於 1761 年，記錄官府勘定的地界、土牛堆和土牛溝的尺寸與數量，也明令禁止漢人越界私墾。

這是可以實際觀察清代番界政策的珍貴古物。

來源：臺中市文化資產處〈土牛民番地界碑〉。tchac.taichung.gov.tw

【段考重點】題目若出現「界碑、土牛溝、禁止私墾、原漢生活區域」，應聯想到劃界封山政策。

四、清帝國的行政區劃為什麼不斷改變？

1. 清帝國初期的行政制度

【三版共通】

1684 年，清廷將臺灣納入福建省管理，設立臺灣府，下轄三縣。

福建省 / 臺灣府 / 臺灣縣 / 今臺南一帶 / 鳳山縣 / 今高雄、屏東一帶 / 諸羅縣 / 今臺南以北廣大地區

這時的臺灣縣、鳳山縣與諸羅縣範圍很大，並非等同今日同名行政區。

隨著人口增加與土地開發，原本的行政制度已逐漸不敷使用。

但清廷初期往往不是單純因為人口變多就立刻調整行政區，而是在發生民變、治安問題或外力威脅後，才採取比較積極的措施。

2. 朱一貴事件與中北部行政區調整

【三版共通】

1721 年，朱一貴號召群眾反抗清廷，雖然最後被平定，仍使清廷意識到臺灣地方管理不足。

因此，清廷於雍正年間增設彰化縣、淡水廳等行政區。

事件因果：

朱一貴事件 → 清廷發現原有行政管理不足 → 增設行政區 → 加強對中北部的控制。

3. 林爽文事件與嘉義地名

【康軒、翰林】

1786 年底至 1787 年，林爽文事件擴大，清廷動員大量軍隊平定。

當時諸羅縣城的部分居民協助清軍守城。乾隆皇帝為了嘉獎他們的忠義，於 1787 年將「諸羅縣」改名為「嘉義縣」。

嘉義的名稱，可以用「嘉獎忠義」來記憶。

【南一、翰林】 另外介紹清代三大民變：

事件 時間 地點或特色
朱一貴事件 1721 年 康熙末年，促成中北部行政調整
林爽文事件 1786－1788 年 乾隆年間，清代臺灣最大規模的民變
戴潮春事件 1862 年起 同治年間，以中部為主要活動區域

【段考重點】不要將朱一貴事件和林爽文事件混淆：

  • 朱一貴事件：與增設彰化縣、淡水廳有關。
  • 林爽文事件：與諸羅改名嘉義有關。

真實地名來源： 中央研究院臺灣史研究所的清代行政區劃資料記載，1787 年因諸羅縣民協助守城，清廷將諸羅改名嘉義。

來源：中央研究院〈清代臺灣行政區劃沿革〉。thcts.sinica.edu.tw

4. 噶瑪蘭廳的設立

【三版共通】

噶瑪蘭是今日宜蘭地區的歷史名稱之一。

18 世紀末以後，漢人移墾增加，與當地原住民族的土地衝突日益頻繁，加上沿海曾遭海盜侵擾，促使清廷考慮設官管理。

【康軒、翰林】 特別提到吳沙率領漢人進入蛤仔難地區開墾。

1812 年，噶瑪蘭廳正式設立。

【延伸補充】「噶瑪蘭」與蘭陽平原原住民族的歷史有關，不是由漢人移民憑空創造的名稱。今天的宜蘭地名與族群歷史，能幫助學生理解清代行政範圍的變化。

來源：宜蘭縣政府〈行政區簡介〉。宜蘭縣政府全球資訊網 - Yilan County Government

觀察行政區劃地圖時，應理解清廷設官管理的範圍，隨著統治、移墾與軍事需求，大致由西部逐步擴及東部，西部的行政區也逐漸由南部向北部增加。

但這不代表東部在設官前「沒有居民」，也不代表清廷宣布設官後就能完全控制當地所有部落。

五、19 世紀中期：外力入侵改變清廷治臺政策

1. 開港通商為什麼重要？

【三版共通】

19 世紀中期，清帝國與英、法等西方國家爆發戰爭。

清廷戰敗後被迫簽訂條約，臺灣陸續開放港口通商。

重要通商口岸包括：

港口名稱 現今位置
淡水 新北市淡水區
雞籠 基隆市
安平 臺南市安平區
打狗 高雄市

開港通商後，外國商人、船隻與各種國際勢力更頻繁地進入臺灣。

這也使清廷逐漸感受到：臺灣不再只是需要防止內亂的邊疆，而是攸關國際貿易與國防安全的重要地區。

【易混淆】 開港通商不等於港口被外國永久占領，也不等於臺灣在當時成為獨立國家。

六、牡丹社事件：日本出兵臺灣南部

1. 事件背景

【三版共通】

1871 年，一艘琉球船隻因風浪漂流到臺灣南部恆春半島。

部分船民上岸後，因語言、文化與部落領域等因素，與當地原住民族發生衝突，造成船民死亡。

1874 年，日本以保護船民、懲辦加害者為藉口，出兵臺灣南部，與牡丹社、高士佛社等部落發生戰爭。

這一連串事件，在國中歷史課本中稱為「牡丹社事件」。

2. 事件因果關係

1871 年：琉球船民遭遇船難，與原住民族發生衝突 / 1874 年：日本出兵臺灣南部 / 排灣族部落抵抗日軍，戰事擴大 / 清廷派沈葆楨來臺，加強防務與對外交涉 / 清廷調整治臺態度，加強軍事與行政建設

3. 為什麼日本要出兵？

日本正處於向外擴張的時期，除了以船民遇害事件為藉口，也希望擴大自身在東亞的影響力。

清、日之後達成外交協議。清廷在相關條款中承認日本出兵具有「保民義舉」的性質，日本則利用此一結果強化其對琉球的政治主張。

【易混淆】不能將牡丹社事件簡化成「因為語言不通，所以日本才打臺灣」。

船民遇害是直接導火線，但日本的海外擴張與當時東亞國際政治，同樣是理解事件的重要背景。

4. 原住民族的觀點

過去的事件敘述常將日本或清廷作為主角。

但從當地排灣族部落的角度來看，這也是外國軍隊進入原有生活領域、族人進行武裝抵抗的歷史。

在石門之役中，原住民利用峽谷地形抵抗日軍。相關戰場與歷史遺跡至今仍是重要的文化資產。

來源：文化部文化資產相關資料〈石門古戰場〉。data.boch.gov.tw

5. 真實史蹟：琉球藩民五十四名墓

位於屏東車城的墓碑，與 1871 年琉球船民遇害及 1874 年日本出兵臺灣有關。

日本在事件後立碑，使用「大日本琉球藩民」的名稱，表達其對琉球人的政治主張。

這座墓碑不只記錄遇難者，也反映當時日本與清帝國之間的國際關係。

來源：國立臺灣歷史博物館〈琉球藩民之墓〉。collections.nmth.gov.tw

七、沈葆楨：牡丹社事件後的建設

1. 沈葆楨為什麼來臺？

【三版共通】

1874 年日本出兵臺灣，讓清廷認識到臺灣南部海防與行政管理的不足。

因此派遣沈葆楨來臺，處理軍事防衛及相關善後事務。

沈葆楨的措施不只有興建炮臺，也包括調整行政、解除部分限制與開闢道路。

2. 沈葆楨主要措施

面向 主要政策或建設 歷史目的
行政 增設臺北府、恆春縣、卑南廳等 強化地方治理
移民政策 廢除渡臺禁令 鼓勵來臺移民與拓墾
原住民族政策 解除劃界封山，推行開山撫番 擴大官方管轄與控制
軍事 興建安平、旗後等地炮臺 強化海防
交通 開闢通往東部的北、中、南三路 加強軍事聯繫與東部開發
城防 興建恆春城 強化恆春半島防務

3. 什麼是「開山撫番」？

【三版共通】

這是清廷晚期使用的政策名稱。

所謂「開山」，主要指開闢進入山區與東部的道路；「撫番」則是當時官府對管理、招撫原住民族等措施的歷史用語。

實際執行時，除了接觸、協商與設官，也包含軍事行動及武力鎮壓。

開山撫番不只是交通建設，也是一項擴大統治的政策。

其結果包括：

  • 清廷對東部及山區的活動增加。
  • 漢人移民與拓墾範圍進一步擴大。
  • 部分原住民族土地與自主生活受到新的壓力。
  • 官府與部落之間出現新的衝突。

【易混淆】不能把開山撫番全部解釋成「幫助原住民改善生活」，因為政策中也有強迫服從、土地侵入和軍事鎮壓的面向。

4. 真實史蹟：八通關古道

【南一、翰林延伸、網路查證】

1875 年，在沈葆楨推動開山撫番的背景下，清廷開闢通往東部的道路。

其中中路由吳光亮負責，從今日南投竹山一帶出發，經八通關通往花蓮玉里地區。

這就是清代的八通關古道。

【易混淆】今天所說的八通關古道，包含不同時代的路線。1875 年的清代八通關古道，與日治時期另外修築的八通關越道路，不是完全相同的道路。

來源：玉山國家公園〈八通關古道〉。ysnp.gov.tw

5. 真實史蹟：億載金城

億載金城又稱「二鯤鯓炮臺」，位於臺南安平。

牡丹社事件後，沈葆楨為了強化海防，推動興建西式炮臺，億載金城於 1876 年完工。

這座炮臺是清廷晚期重視海防的重要見證。

來源：臺南市政府文化局〈億載金城〉。historic.tainan.gov.tw

八、清法戰爭與臺灣建省

1. 清法戰爭為什麼發生？

【三版共通】

19 世紀後期，法國積極擴張在越南的勢力，與清帝國發生衝突。

1884 年，清、法兩國爆發戰爭，戰火不只發生在越南與中國沿海，也波及臺灣。

法軍先後進攻基隆、淡水，並在戰爭後期攻占澎湖。

【南一】 課後閱讀〈臺灣封鎖記〉利用英國商人陶德的記錄，呈現清法戰爭期間北臺灣居民及商人受到封鎖的影響。

【康軒】 介紹清法戰爭在臺灣又稱「西仔反」；「西仔」與法蘭西有關。

2. 清法戰爭的重要結果

清法戰爭讓清廷再次意識到臺灣對中國東南海防的重要性。

因此：

1884 年清法戰爭 → 清廷重視臺灣國防 → 1885 年宣布臺灣建省 → 劉銘傳成為首任臺灣巡撫 → 推動現代化建設。

3. 牡丹社事件與清法戰爭比較

【三版共通】

比較項目 牡丹社事件 清法戰爭
時間 1874 年 1884－1885 年
主要外來國家 日本 法國
直接背景 1871 年琉球船民遇害 清、法爭奪越南的政治與軍事影響力
臺灣主要戰場 恆春半島、牡丹社及周邊地區 基隆、淡水、澎湖

【段考重點】最重要的搭配是：

牡丹社事件—日本—沈葆楨；清法戰爭—法國—劉銘傳。

九、劉銘傳與臺灣現代化建設

1. 劉銘傳是誰？

【三版共通】

劉銘傳原是清帝國的重要軍事將領，清法戰爭期間來臺負責防務。

清廷於 1885 年宣布臺灣建省，劉銘傳成為首任臺灣巡撫。

他的施政重點包括加強國防、改善交通與通訊、增進行政管理能力。

2. 劉銘傳的主要建設

類別 主要建設 功能
行政 調整行政區劃，建省後設三府等 提升管理效率
國防 在基隆等地修建新式炮臺 防禦外國軍隊
鐵路 推動基隆至臺北等地鐵路 改善陸上交通
電報 架設臺灣境內及對外電報線 加快訊息傳遞
郵政 設立郵政總局等制度 改善郵件傳遞
航運 購置輪船 加強島內外運輸
教育 設立西學堂、電報學堂等 培養新式技術人才

3. 為什麼鐵路與電報很重要？

鐵路： 可以讓人員、物資及軍事補給更有效率地移動。

電報： 可以讓訊息跨越較遠的距離，不必完全依賴人員與船隻傳遞。

這些建設除了促進交通與商業，也具有軍事與行政功能。

【易混淆】清代並未完成全臺環島鐵路。

清末基隆至臺北的鐵路在 1891 年竣工；臺北至新竹段雖然在劉銘傳任內推動，但直到他卸任後的 1893 年才完成。

來源：中央研究院〈清代鐵路分布圖〉。thcts.sinica.edu.tw

4. 真實史蹟：劉銘傳隧道

劉銘傳隧道，舊稱「獅球嶺隧道」，位於基隆。

隧道是清末臺灣鐵路的重要工程，於 1890 年完工，見證當時開鑿山體、興建新式交通設施的技術與困難。

今日它已是指定古蹟。

來源：文化部國家文化資產網〈劉銘傳隧道〉。National Cultural Heritage Database

【核心觀念】清廷的統治政策並不是一開始就積極建設，也不是突然在某一天全面轉變，而是在民變、人口增加、開港通商及國際軍事威脅下，逐步調整治理方式。

進階思考：清廷的政策真的能達到目的嗎？

【南一、翰林】 都利用清初臺灣府城城牆的變化，讓學生思考官方對防禦設施的態度。

早期清廷擔心，若府城興建堅固城牆，一旦被反抗勢力占領，可能更難收復。

但在民變頻繁後，清廷又逐漸認為城牆有助於官府防守。

這個例子告訴我們：同樣是城牆，政府可能因時代與局勢不同，對它產生相反的看法。

十三、與前後課的連結

連結第 3 課：從鄭氏政權到清帝國

第 3 課中，鄭氏政權推動屯墾，與部分原住民族發生土地衝突。

第 4 課中，清廷面對持續增加的漢人移民與原住民族生活領域的問題，採取了渡臺禁令、劃界封山等措施。

所以可以看出：政權更替了，但臺灣的土地、移民與族群關係問題沒有立刻消失。

連結後續清代社會與經濟內容

第 4 課中，清廷開港通商、修築鐵路、擴大移民及開發土地。

這些變化會影響後續清代臺灣的產業、人口分布、交通、市街發展與社會文化，也是理解臺灣近代發展的重要基礎。

最後的歷史思考

同一項政策，從不同人的角度看，可能產生完全不同的意義。

例如，鄭氏屯墾對官兵可能代表糧食增加，對部分原住民族卻代表土地受到侵占；沈葆楨的開山撫番對清廷是強化防務與控制，對部分原住民族則可能是外來勢力進入生活領域。

學習歷史不只要記住年份、人物與事件，還要能回答：

「為什麼發生？影響誰？對不同的人有什麼意義？」
