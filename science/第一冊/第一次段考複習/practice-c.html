一、單一選擇題 （每題 2.5 分）
1.關於科學探究流程與變因設計，下列敘述何者錯誤？科學方法
A一個良好的實驗可以同時改變多個操縱變因，以便一次比較所有因素
B操縱變因是實驗者刻意改變的因素，每次實驗只改變一個
C應變變因是隨操縱變因而被測量的結果
D控制變因是除操縱變因外必須保持相同的所有條件
【答案】A　【解析】操縱變因每次只能改變一個，若同時改多個就無法判斷是哪個因素造成差異，這是常見迷思。
2.小明想研究「光照強度是否影響水蘊草產生氣泡的速率」，下列何者是這個實驗的操縱變因？科學方法
A光照強度
B水蘊草的種類與長度
C水的溫度
D每分鐘產生的氣泡數
【答案】A　【解析】操縱變因是刻意改變的因素（光照強度）；氣泡數是應變變因；水溫與水蘊草條件應保持相同屬控制變因。
3.設計實驗時設置「對照組」的主要目的是什麼？科學方法
A提供一個比較基準，以判斷操縱變因是否真的造成差異
B增加實驗的操縱變因數目
C讓實驗看起來比較複雜
D取代重複實驗的必要性
【答案】A　【解析】對照組不施加操縱變因，作為比較基準；有了對照才能確認差異是操縱變因造成，並非讓實驗變複雜。
4.下列單位換算何者正確？科學方法
A1 L = 100 mL
B1 m = 10 cm
C1 mm = 1000 µm
D1 cm = 100 mm
【答案】C　【解析】1 mm=1000 µm 正確。其餘：1 m=100 cm、1 L=1000 mL、1 cm=10 mm，皆錯。
5.關於生物的共同特徵，下列敘述何者錯誤？生命現象
A生物能排除體內代謝廢物
B生物能繁殖產生後代
C生物能對外界刺激產生感應
D所有生物都不需要從外界獲得營養，能自行無中生有製造能量
【答案】D　【解析】生物都需要營養（自營或異營），沒有生物能無中生有製造能量，違反能量守恆，此為錯誤敘述。
6.關於病毒的敘述，下列何者最正確？生命現象
A病毒能單獨在空氣中自行繁殖後代
B病毒完全不具任何生命特徵，與石頭無異
C病毒具有完整的細胞構造，可獨立生活
D病毒無細胞構造，能繁殖但必須寄生在宿主細胞內，介於生物與非生物之間
【答案】D　【解析】病毒無細胞構造、須寄生宿主細胞才能繁殖，具部分生命特徵，常被視為介於生物與非生物間的特例。
7.關於「生物圈」，下列敘述何者錯誤？生命現象
A生物圈是地球上所有生物與其生存環境的總和
B生物圈是目前已知唯一有生命存在的區域
C生物圈涵蓋大氣圈下層、水圈與岩石圈表層的交會處
D生物圈的範圍恆定不變，且僅限於陸地表面
【答案】D　【解析】生物圈範圍並非恆定不變、也不只限陸地，還包含水圈與大氣下層，從高山到深海，此敘述錯誤。
8.下列關於生態層次由小到大的排列，何者正確？生命現象
A族群 → 個體 → 群集 → 生物圈 → 生態系
B個體 → 群集 → 族群 → 生物圈 → 生態系
C生物圈 → 生態系 → 群集 → 族群 → 個體
D個體 → 族群 → 群集 → 生態系 → 生物圈
【答案】D　【解析】由小到大依序為個體→族群→群集→生態系→生物圈，這是入門的生態層次順序。
9.下列何者可判斷「機器人」不是生物？生命現象
A機器人不需要電力
B機器人不會移動
C機器人體積太大
D機器人無法自行繁殖產生後代，也不是由細胞組成
【答案】D　【解析】生物由細胞組成、能繁殖與自我調節；機器人非細胞構成也不能繁殖後代，故非生物。會不會移動不是判斷依據。
10.使用複式顯微鏡時，若目鏡為15×、物鏡為40×，則總放大倍率為多少？顯微鏡
A55 倍
B150 倍
C600 倍
D400 倍
【答案】C　【解析】總放大倍率＝目鏡×物鏡＝15×40＝600 倍；是相乘不是相加（15+40=55 為錯誤迷思）。
11.關於顯微鏡由低倍率轉換到高倍率時視野的變化，下列敘述何者錯誤？顯微鏡
A看到的每個細胞會變大
B視野會變小、變暗
C視野會變大、變亮，看到的細胞數目變多
D看到的細胞數目會變少
【答案】C　【解析】低倍轉高倍時視野變小、變暗、細胞數目變少但每個變大，故「視野變大變亮、細胞變多」為錯誤敘述。
12.在顯微鏡高倍率下對焦時，應使用下列何者以避免壓破玻片或撞壞物鏡？顯微鏡
A光圈
B粗調節輪
C細調節輪
D反光鏡
【答案】C　【解析】高倍對焦只能用細調節輪，微幅調整以免物鏡下壓壓破玻片；粗調節輪僅在低倍時使用。
13.在複式顯微鏡視野中，某細胞出現在視野的「右下方」，要把它移到視野中央，應將玻片往哪個方向移動？顯微鏡
A左下方
B右下方
C左上方
D右上方
【答案】B　【解析】顯微鏡成像上下左右相反，但玻片移動方向與影像移動方向相同，影像在右下就往右下推，東西在哪就往哪推。
14.關於細胞壁與細胞膜的比較，下列敘述何者錯誤？細胞構造
A細胞壁具有選擇通透性，能控制物質進出細胞
B細胞壁主成分為纖維素，提供支持與保護
C細胞壁位於細胞膜的外側，且動物細胞沒有細胞壁
D細胞膜具選擇通透性，能控制物質進出
【答案】A　【解析】控制物質進出的是細胞膜；細胞壁是全通透、不能選擇，只負責支持保護，此為經典迷思題。
15.下列何種胞器負責進行呼吸作用、產生細胞所需的能量，被稱為「細胞的發電廠」？細胞構造
A細胞壁
B粒線體
C液泡
D葉綠體
【答案】B　【解析】粒線體進行呼吸作用產生能量，是細胞發電廠；葉綠體行光合作用製造養分，兩者功能不同。
16.下列關於動物細胞與植物細胞的比較，何者錯誤？細胞構造
A動物細胞與植物細胞都具有細胞壁與葉綠體
B動、植物細胞都有細胞膜、細胞質與細胞核
C能行光合作用的植物細胞才有葉綠體
D植物細胞有細胞壁，動物細胞沒有
【答案】A　【解析】細胞壁與葉綠體是植物細胞特有，動物細胞兩者皆無，故此敘述錯誤。
17.觀察「洋蔥表皮細胞」時，下列敘述何者正確？細胞構造
A因是植物細胞，故一定能進行光合作用
B洋蔥表皮細胞沒有細胞壁
C可見到細胞壁與細胞核，但看不到葉綠體
D可見到大量綠色的葉綠體
【答案】C　【解析】洋蔥表皮雖是植物細胞有細胞壁與細胞核，但不含葉綠體（不行光合作用），只有水蘊草葉等綠色細胞才有葉綠體。
18.關於細胞核的功能，下列何者正確？細胞構造
A內含遺傳物質DNA，是控制細胞生命活動的中心
B負責產生能量供呼吸作用使用
C主要負責支持與維持細胞形狀
D是進行光合作用製造養分的場所
【答案】A　【解析】細胞核含DNA，是控制細胞生命活動的中心；光合在葉綠體、支持靠細胞壁、產能在粒線體。
19.細胞學說的內容不包含下列哪一項？細胞構造
A所有細胞都能行光合作用自製養分
B所有生物體都由細胞構成
C細胞是生物體構造與功能的基本單位
D細胞由既有的細胞分裂而來
【答案】A　【解析】細胞學說三要點為生物由細胞構成、細胞是基本單位、細胞來自既有細胞分裂；並非所有細胞都能光合，故此項不屬細胞學說。
20.多細胞生物體的組成層次，由簡單到複雜的正確順序為何？組成層次
A細胞 → 組織 → 器官 → 器官系統 → 個體
B細胞 → 組織 → 器官系統 → 器官 → 個體
C組織 → 細胞 → 器官 → 個體 → 器官系統
D細胞 → 器官 → 組織 → 器官系統 → 個體
【答案】A　【解析】正確層次為細胞→組織→器官→器官系統→個體，組織由相似細胞組成，器官由不同組織協同。
21.關於單細胞生物（如變形蟲、草履蟲）的敘述，下列何者錯誤？組成層次
A一個細胞即可完成所有生命活動
B牠們不具有組織與器官的層次
C單細胞生物也具有組織、器官與器官系統等層次
D細菌也屬於單細胞生物
【答案】C　【解析】單細胞生物僅一個細胞就完成所有生命活動，不具組織、器官層次，此敘述錯誤。
22.生物體能由小長大，主要是靠下列何種方式？組成層次
A細胞壁不斷向外堆疊變厚
B單一細胞無限制地變得超級大
C細胞內液泡不斷吸水膨脹
D細胞數目增多（細胞分裂）
【答案】D　【解析】生物長大主要靠細胞分裂使數目增多，而非單一細胞無限長大，這是常見迷思。
23.下列關於「組織」的敘述何者正確？組成層次
A組織是由形態相似、功能相同的細胞集合而成
B植物沒有組織這個層次
C一個組織就等於一個完整的個體
D組織是由多個器官合作構成
【答案】A　【解析】組織是形態相似、功能相同的細胞集合（如上皮組織、表皮組織）；多器官合作是器官系統，植物也有組織。
24.關於「擴散作用」，下列敘述何者錯誤？擴散
A擴散是分子自發的運動
B肺泡與微血管間氧氣與二氧化碳的交換屬於擴散
C擴散作用需要消耗細胞的能量才能進行
D擴散是物質分子由濃度高處往濃度低處移動
【答案】C　【解析】擴散是被動運輸、不需消耗能量，只有主動運輸才耗能，故「需消耗能量」為錯誤敘述。
25.下列哪一種現象「不是」主要靠擴散作用完成？擴散
A根細胞逆濃度差主動吸收特定礦物質離子
B一滴墨水在清水中慢慢均勻散開
C香水噴出後在空氣中逐漸散開
D肺泡中的氧氣進入微血管
【答案】A　【解析】逆濃度差的主動吸收屬主動運輸、需耗能，不是擴散；其餘皆為順濃度差的擴散現象。
26.下列哪一項會使擴散速率「變慢」？擴散
A溫度升高
B兩側濃度差變小
C擴散距離縮短
D接觸面積增大
【答案】B　【解析】濃度差越小擴散越慢；溫度升高、距離變短、面積變大都會使擴散變快。
27.關於擴散方向的敘述，下列何者正確？擴散
A氣體不會擴散，只有液體才會擴散
B擴散只能發生在活細胞中，死細胞完全不會擴散
C擴散方向是由低濃度往高濃度移動
D擴散方向由濃度梯度決定，由高濃度往低濃度移動
【答案】D　【解析】擴散由濃度梯度決定、高往低移動，與細胞是否存活無關（死細胞膜失選擇性物質仍會擴散），氣體液體皆會擴散。
28.將一塊方糖放入靜置的溫水杯中，一段時間後整杯水都變甜，這是因為？擴散
A水分子透過半透膜滲透進入糖塊
B糖分子被水主動運輸並消耗能量帶往各處
C糖分子逆濃度差往高濃度移動
D糖分子由濃度高處往低處擴散，最後均勻分布
【答案】D　【解析】整杯變甜是糖分子擴散、由高濃度往低濃度自發移動至均勻分布，不耗能、也不需半透膜。
29.關於「滲透作用」，下列敘述何者錯誤？滲透
A滲透是一種特殊的擴散，屬被動運輸不耗能
B水分子會往溶質濃度高（水濃度低）的一側移動
C滲透作用移動的是溶質分子，由溶質濃度低往高移動
D滲透是水分子透過半透膜的移動
【答案】C　【解析】滲透移動的是水分子而非溶質，這是最常見的迷思；水往溶質濃度高的一側走，且不耗能。
30.將人類紅血球放入「蒸餾水」中，一段時間後最可能發生什麼變化？滲透
A水淨流入紅血球，使紅血球脹大甚至破裂（溶血）
B水淨流出紅血球，使紅血球皺縮
C紅血球形狀完全不變
D紅血球長出細胞壁保護自己
【答案】A　【解析】蒸餾水對紅血球是低張溶液，水淨流入使其脹大甚至破裂（溶血）；動物細胞無細胞壁故會破。
31.將「植物細胞」放入蒸餾水（低張溶液）中，下列敘述何者正確？滲透
A細胞會發生質壁分離
B細胞會像紅血球一樣脹破
C細胞完全不會吸水
D細胞吸水膨脹，但因有細胞壁支撐只脹到膨壓不會破裂
【答案】D　【解析】植物細胞在低張液吸水膨脹，但細胞壁提供支撐使其只脹到產生膨壓、不會破裂，此為與動物細胞的關鍵差異。
32.將水蘊草細胞放入「濃食鹽水（高張溶液）」中，最可能觀察到下列何種現象？滲透
A水淨流出，發生質壁分離，原生質層與細胞壁分離
B細胞吸水脹大變硬挺
C細胞形狀完全不變
D細胞脹破流出內含物
【答案】A　【解析】高張溶液使水淨流出植物細胞，原生質層收縮與細胞壁分離，稱為質壁分離，細胞變軟。
33.下列關於「保衛細胞（屬植物細胞，有細胞壁）」在不同溶液中的敘述，何者錯誤？滲透
A保衛細胞放在濃食鹽水中會因失水而改變膨壓
B保衛細胞放在濃食鹽水或蒸餾水中，細胞都不會有任何改變
C保衛細胞放在蒸餾水中不會脹破
D保衛細胞放在蒸餾水中會因吸水而膨脹
【答案】B　【解析】保衛細胞仍會因滲透在不同溶液中得水或失水改變膨壓，「都不會改變」是錯誤敘述；只是有細胞壁不會脹破。
34.用鹽或糖大量醃漬食物可防腐，其主要原理為何？滲透
A鹽或糖能加快微生物體內的擴散使其死亡
B鹽或糖能提供微生物大量養分使其死亡
C高濃度的鹽或糖使外界成高張溶液，讓微生物滲透失水而難以生存
D高濃度鹽糖使外界成低張溶液，讓微生物吸水脹破
【答案】C　【解析】鹽漬糖漬使外界變高張，微生物因滲透失水（脫水）而難以生存，達到防腐效果。
35.將紅血球放入「0.9% 生理食鹽水（等張溶液）」中，最可能發生什麼？滲透

B紅血球長出葉綠體

36.甲、乙、丙三個相同的動物細胞分別放入不同溶液（如表），最可能發生何種變化？滲透
細胞所在溶液溶液張力
甲蒸餾水低張
乙生理食鹽水等張
丙濃食鹽水高張
A甲、乙、丙都脹破
B甲皺縮、乙不變、丙脹破
C甲脹破、乙不變、丙皺縮
D甲、乙、丙都皺縮
【答案】C　【解析】低張(甲)水流入脹破、等張(乙)不變、高張(丙)水流出皺縮；動物細胞無細胞壁故低張會破。
37.關於物質進出細胞的方式，下列敘述何者錯誤？物質進出
A擴散與滲透都是被動運輸，順濃度梯度且不耗能
B主動運輸可逆濃度梯度移動，需消耗能量
C胞吞與胞吐運送大分子或顆粒，需耗能與細胞膜變形
D擴散與滲透都屬於主動運輸，都需要消耗細胞能量
【答案】D　【解析】擴散與滲透是被動運輸、不耗能；只有主動運輸與胞吞胞吐才需耗能，故此敘述錯誤。
38.邊長為 2 的立方體，其「表面積 / 體積」比值為多少？物質進出
A12

39.關於「細胞為什麼要維持很小的體積」，下列敘述何者正確？物質進出
A細胞越小，表面積/體積比越小，交換效率越差
B細胞越小，表面積/體積比越大，物質進出交換效率越高
C細胞越大，表面積/體積比越大，交換越快
D細胞大小與物質交換效率完全無關
【答案】B　【解析】細胞越小表面積/體積比越大，物質交換效率越高；故細胞維持小體積、靠增加數目長大。
40.根細胞逆著濃度梯度主動吸收土壤中某些礦物質離子，這種運輸方式的能量主要由何者提供？物質進出
A粒線體進行呼吸作用所產生的能量
B細胞壁分解纖維素提供
C葉綠體進行光合作用直接提供
D擴散作用自發提供，不需能量
【答案】A　【解析】逆濃度差的主動運輸需耗能，能量由粒線體呼吸作用提供；擴散不耗能、細胞壁不供能。
